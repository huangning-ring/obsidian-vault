# 1 必须知道的3个快捷键
新手在使用Obsidian时，记住下面这三个快捷键非常有用！
- 展开左侧边栏：`Ctrl` + `Alt` + `[`；
- 展开右侧边栏：`Ctrl` + `Alt` + `]`；
- 打开软件设置：`Ctrl` + `,`如果这个快捷键没反应，请尝试用`Alt` + `,`。

# 4 预装插件
为减少新手会员使用门槛，析径默认安装了一些第三方插件，其中有些插件是使用析径任务管理系统的必备插件，接下来对各个插件的用途和注意事项做一些简单的介绍。
## 4.1 必备插件
### 4.1.1 Tasks
**用途介绍**：用于实现任务清单、任务提醒、本周代办任务、任务回顾等功能。更多用法推荐查阅官方的[用户指南](https://publish.obsidian.md/tasks/Introduction)。
**启用建议**：*必须启用*
**注意事项**：作为析径的必备插件，禁用后将无法正常运行析径。
### 4.1.2 Dataview
**用途介绍**：用于实现各类图表数据查询、任务清单。更多用法推荐查阅官方的[用户指南](https://blacksmithgu.github.io/obsidian-dataview/)。
**启用建议**：*必须启用*
**注意事项**：作为析径的必备插件，禁用后将无法正常运行析径。
### 4.1.3 Contribution Graph
**用途介绍**：用于生成习惯打卡、任务生成规律等热力图。使用方法可参考这篇开发者写的[使用教程](https://mp.weixin.qq.com/s/ZJy6-fhtj9WlJQ5ndEXfBw)。
**启用建议**：*必须启用*
**注意事项**：作为析径的必备插件，禁用后将无法正常运行析径。
## 4.2 推荐插件
### 4.2.1 增强编辑
**用途介绍**：能够为文字样式增加很多快捷键，比如删除线、下划线、去除空格、一件空行、复制无格式文本...
**启用建议**：*推荐启用*
**注意事项**：你可以在`设置-快捷键`页面搜索`增强编辑`查看支持的快捷键并自行更改。该插件很久没有维护，有些快捷键似乎已经失效了。
### 4.2.2 Clear Unused Images
**用途介绍**：用于清除笔记中未被引用的图片或附件。支持通过命令面板调用或结合Commander插件点击按钮调用。
**启用建议**：*推荐启用*
**注意事项**：如禁用插件，页首位置对应的清除图片命令按钮将不可用。
### 4.2.3 Commander
**用途介绍**：用于在页首位置添加常用命令按钮。
**启用建议**：*推荐启用*
**注意事项**：如禁用插件，页首位置将不展示常用命令按钮。
### 4.2.4 Consistent Attachments and Links
**用途介绍**：删除笔记时自动删除附件；移动笔记时，自动跟随笔记移动附件
**启用建议**：*推荐启用*
**注意事项**：由于涉及到高风险操作，建议您充分测试各种可能的情况，验证插件可靠性之后，再决定是否启用插件。
### 4.2.5 Copilot
**用途介绍**：通过API调用大模型，让AI基于提示词帮助拆解目标计划
**启用建议**：*需要时启用*
**注意事项**：API费用需自行付费购买。该插件会拖慢Obsidian开机速度，建议需要用时手动启用。插件在2.9.0版本之后提示词不支持文件夹嵌套管理。
### 4.2.6 Hover Editor
**用途介绍**：按住Ctrl时，配合鼠标悬浮在双链上可以预览、编辑笔记内容。相比Obsidian官方自带的功能，这个插件的优势在于可以同时预览多篇笔记，支持拖动并固定预览窗口。
**启用建议**：*推荐启用*
**注意事项**：无
### 4.2.7 Linter
**用途介绍**：用于自动更新模板里的title、dateUpdate属性，保持笔记属性统一。更多用法推荐查阅官方的[用户指南](https://platers.github.io/obsidian-linter/)。
**启用建议**：*推荐启用*
**注意事项**：该插件默认会按设定的属性触发时机对所有笔记统一更新笔记属性，如不希望某些文件受影响，需要在基础设置页面添加忽略文件夹。
### 4.2.8 Local Images Plus
**用途介绍**：剪藏网页信息时，将网络图片保存到本地，避免失效。
**启用建议**：*推荐启用*
**注意事项**：如禁用插件，页首位置对应的下载图片命令按钮将不可用。
### 4.2.9 Novel word count
**用途介绍**：统计各个文件夹下笔记数量和文件大小，可自定义显示。
**启用建议**：*推荐启用*
**注意事项**：如禁用插件，文件夹右侧将不显示笔记相关信息。
### 4.2.10 Number Headings
**用途介绍**：能够在各级标题前面自动添加、更新序号。
**启用建议**：*推荐启用*
**注意事项**：自动编号可能会让你之前双链里引用的标题失效，造成的后果就是双链可能无法精准链接到某个段落标题。
### 4.2.11 Plugin Manager
**用途介绍**：可对非必要插件的设置延迟启动，加快Obsidian打开速度。
**启用建议**：*推荐启用*
**注意事项**：当想禁用某个插件时，需要在Plugin Manager里也设置关闭。
### 4.2.12 QuickAdd
**用途介绍**：实现通过快捷键往个人、家庭、工作、事业等领域快速添加日常任务。更多用法详见官方的[用户指南](https://quickadd.obsidian.guide/docs/)。
**启用建议**：*推荐启用*
**注意事项**：默认分配的快捷键分别是：`Ctrl + Alt + M`（个人日常任务）、`Ctrl + Alt + J`（工作日常任务）、`Ctrl + Alt + H`（家庭日常任务）、`Ctrl + Alt + B`（事业日常任务）。可在`设置-快捷键`页面搜索`quickAdd`自行更改。
### 4.2.13 Quiet Outline
**用途介绍**：比官方更好用的笔记大纲，在笔记数字多的时候依然很稳定。支持层级切换、自动折叠功能。
**启用建议**：*推荐启用*
**注意事项**：无
### 4.2.14 Style Settings
**用途介绍**：能修改很多主题样式，定制更适合自己的软件页面。
**启用建议**：*推荐启用*
**注意事项**：可设置的内容与当前使用的主题有关，有些主题不支持样式设置，有些主题的设置项是英文的。
### 4.2.15 Templater
**用途介绍**：在特定文件夹里创建笔记时，统一应用固定格式的笔记模板。更多用法推荐查阅官方的[用户指南](https://silentvoid13.github.io/Templater/)。
**启用建议**：*推荐启用*
**注意事项**：Templater调用模板的快捷键默认是`Alt + E`，同样允许在`设置-快捷键`中搜索`Templater`自行更改。官方核心插件里也有一个模板插件（为避免误导已被关闭）。析径默认为一些文件夹指定了模板，你可以在Templater的设置页面查看具体哪些文件夹应用了笔记模板。
