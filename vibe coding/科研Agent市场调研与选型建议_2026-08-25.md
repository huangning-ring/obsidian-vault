# 全流程科研 Agent 市场调研与选型建议
> 调研日期：2026-08-25  
> 调研对象：历史先驱、具有代表性的全流程或准全流程科研 Agent，以及对生物医学研究最有实际价值的产品  
> 付费信息：以调研日可见的官方页面为准；预览期、学术额度和企业合同可能随时变化

## 结论先行
不存在一个在所有口径下都成立的“最早全流程科研 Agent”。更准确的结论是：
1. **最早的闭环 Robot Scientist**：2004 年的 Robot Scientist 已能自动提出假设、设计实验、用实验室机器人执行、解释结果并重复循环；2009 年的 Adam 进一步报告了自主产生并实验验证新的酵母功能基因组学知识。[38][1]
2. **LLM 时代第一波连接实体实验的科研 Agent**：ChemCrow 与后来发展为 Coscientist 的 Agent 论文都在 2023-04-11 公开。按 arXiv 元数据，Coscientist 前身早约 51 分钟，但当时尚未使用 Coscientist 名称；按稳定产品名称，ChemCrow 更早公开。最稳妥的结论是二者同日、并行开创了 LLM 化学科研 Agent 路线。[15][46]
3. **最早形成“想法—代码—实验—图表—论文—评审”通用计算闭环的代表**：Sakana AI 的 The AI Scientist 于 2024 年 8 月公开，首次系统展示了机器学习研究从选题到论文的端到端自动化。[40]
4. **生物医学实验闭环最有说服力的代表**：Robin 把文献检索、疾病机制与药物假设、实验策略、湿实验结果分析和下一轮假设接成连续流程，但实体实验仍由人完成。[22]
5. **当前最像可购买“数据驱动 AI 科学家”的产品**：Kosmos 能围绕给定目标和数据集，长时间循环执行文献检索、代码分析、假设生成与报告写作；它已经商业化，但 2026 年正在从旧版按次产品切换到申请制的新 Kosmos。[25][29]
6. **与你当前研究最匹配的实际组合**：短期优先尝试 **Biomni + Google Co-Scientist/Hypothesis Generation + Hermes**；有高质量组学或筛选数据后，再评估 Kosmos。Robin 适合药物重定位和实验策略排序；Sakana AI Scientist 与 Agent Laboratory 不应作为湿实验主流程的首选。
## 如何界定“全流程”
本报告把科研流程拆为六个环节：
1. 文献检索与问题界定；
2. 假设生成及新颖性判断；
3. 实验或分析方案设计；
4. 计算实验或实体实验执行；
5. 数据分析、结果解释和下一轮迭代；
6. 可追溯报告、论文或决策材料生成。
据此分为四类：
- **实体闭环型**：系统能直接控制机器人或通过云实验室执行实体实验。
- **Lab-in-the-loop 型**：AI 完成主要认知环节，人执行湿实验，再把结果交还 AI 分析和迭代。
- **计算/数据闭环型**：能自主写代码、运行计算实验、分析数据并形成报告，但不操作湿实验。
- **科研协作型**：覆盖多个环节，却仍以假设、协议、工具编排或单轮分析为主。
“能写一篇看起来像论文的文本”不等于完成科研闭环；“能提出好假设”也不等于完成实验验证。

## 代表系统详评
### 1. Robot Scientist / Adam：历史最早的真正闭环先驱
**作者与团队**：Ross D. King 团队；2004 年论文作者包括 Ross D. King、Kenneth E. Whelan、Ffion M. Jones、Philip G. K. Reiser、Christopher H. Bryant、Stephen H. Muggleton、Douglas B. Kell 和 Stephen G. Oliver；2009 年 Adam 论文由 Ross D. King、Jem Rowland、Stephen G. Oliver、Michael Young、Wayne Aubrey、Emma Byrne、Maria Liakata、Magdalena Markham、Pinar Pir、Larisa N. Soldatova 等完成。[38][1]
**功能**：围绕酵母基因功能建立形式化知识模型，自动提出解释性假设，选择最有信息量的实验，用机器人执行培养与测量，排除不符合数据的假设，再进入下一轮。2009 年系统已管理数百万次生物量测量及其逻辑描述。[38][1]
**付费与可用性**：这是实验室基础设施和研究原型，不是面向市场的 SaaS，也没有公开订阅价格。
**评价**：如果“全流程”要求真实实验反馈，而不是生成论文，Adam 才是历史基准。它的弱点不是自动化程度，而是领域极窄、硬件昂贵、知识表示和实验空间需要人工预先工程化。
### 2. ChemCrow：较早的 LLM 化学工具 Agent
**作者与时间**：Andres M. Bran、Sam Cox、Oliver Schilter、Carlo Baldassari、Andrew D. White、Philippe Schwaller；预印本于 2023-04-11 提交，后发表于 Nature Machine Intelligence。[15]
**功能**：把 GPT-4 与 18 个化学工具结合，覆盖有机合成、药物发现与材料设计；论文展示了驱虫剂和三种有机催化剂的自主合成规划与执行，并辅助发现新型发色团。[15]
**付费与可用性**：公共仓库采用 MIT License，可通过 `pip` 使用，但需要模型 API；部分论文工具因 API 使用限制没有放入公共版本，RXN4Chemistry 等服务还需额外账号或自托管资源，因此“开源”不等于完整复现或零成本。[13]
**评价**：它是工具增强科研 Agent 的关键早期范式，但更像强大的化学任务执行器，不是从研究问题到论文的通用科研操作系统。对你的呼吸道病毒研究直接价值较低。
### 3. Coscientist：LLM 与自动化化学实验的标志性结合
**作者与时间**：2023-04-11 的前身论文由 Daniil A. Boiko、Robert MacKnight、Gabe Gomes 完成；扩展版增加 Ben Kline，并于 2023 年 12 月以 Coscientist 名称发表于 Nature。[46][10]
**功能**：调用互联网和设备文档检索、代码执行、实验规划与自动化仪器接口；展示了钯催化交叉偶联优化、云实验室操作、液体处理和多模块实验。CMU 将其描述为首个设计、规划并执行化学实验的非有机智能系统。[10][12]
**付费与可用性**：研究原型，没有公开自助产品或固定价格。实体执行依赖自动化实验室或 Emerald Cloud Lab 等基础设施，实际成本远高于单纯模型调用。
**评价**：Coscientist 比 ChemCrow 更接近“实验操作系统”，也更重视可追溯性和安全，但它仍局限于化学自动化环境。其真正价值在于证明 LLM 可以充当不同实验设备和文档之间的自然语言控制层。
### 4. The AI Scientist v1/v2：计算科研到论文闭环的影响力代表
**作者与时间**：v1 由 Chris Lu、Cong Lu、Robert Tjarko Lange、Jakob Foerster、Jeff Clune、David Ha 等完成，2024-08-12 首次公开；v2 由 Yutaro Yamada、Robert Tjarko Lange、Cong Lu、Shengran Hu、Chris Lu、Jakob Foerster、Jeff Clune、David Ha 完成，2025-04-10 公开。[40][4]
**功能**：v1 从研究想法、文献新颖性检查、代码编写、计算实验、图表到 LaTeX 论文和自动评审形成闭环；v2 去掉了必须依赖人类代码模板的限制，以 Agentic Tree Search 探索实验，并生成了一篇通过 ICLR workshop 同行评审的全 AI 论文。2026 年该路线正式发表于 Nature。[40][4][41]
**付费与可用性**：代码可下载，但当前仓库采用 The AI Scientist Source Code License，并要求对 AI 生成论文进行显著披露，不应再简单称为无条件 Apache 2.0 开源。v1 官方估算通常低于 15 美元/篇；v2 实验阶段约 15–20 美元/次，写作再约 5 美元，另需 NVIDIA GPU、模型 API 和 Semantic Scholar 访问。[5][6]
**评价**：影响力很大，但“论文闭环”主要发生在可以用代码表达的机器学习研究中。它容易把完成格式、跑通代码和生成可发表文本误当作高质量科学；官方也承认会产生幼稚假设、方法严谨性不足、错误引用和重复图片。[3] 对你的湿实验主线，它更适合作为计算子课题和流程设计参考，而不是主科研 Agent。
### 5. Agent Laboratory：更务实的人机协作型开源流程
**作者与时间**：Samuel Schmidgall、Yusheng Su、Ze Wang、Ximeng Sun、Jialian Wu、Xiaodong Yu、Jiang Liu、Michael Moor、Zicheng Liu、Emad Barsoum；2025-01-08 首次提交。[9]
**功能**：接收人提出的研究想法，依次进行文献综述、实验计划与机器学习代码执行、报告写作；允许人在每个阶段反馈，并输出代码仓库和研究报告。[7]
**付费与可用性**：代码为 MIT License；论文报告的单工作流模型成本约为 GPT-4o 2.33 美元、o1-mini 7.51 美元、o1-preview 13.10 美元，不含本地算力和人工验证成本。[7][8]
**评价**：它没有 The AI Scientist 那么“自主”，但人机协作模式更符合真实科研。论文中的人评结果也显示，自动模式产出仍明显低于被接收 NeurIPS 论文，而加入人类反馈能提高质量。[7] 如果要自己部署计算科研管线，它比追求无人值守更合理。
### 6. Google Co-Scientist：最强势的假设生成与科学辩论路线之一
**作者与时间**：项目由 Juraj Gottweis、Vivek Natarajan 等领导，Google Research、Google DeepMind、Google Cloud 与多家生物医学机构共同完成；2025-02-19 首次公开，2026-05 发表于 Nature，并以 Gemini for Science 的 Hypothesis Generation 实验工具向个人研究者逐步开放。[16][18][17]
**功能**：Generation、Reflection、Ranking、Evolution、Proximity、Meta-review 等 Agent 对假设进行生成、批评、两两辩论、排名和演化，并给出实验协议。系统在急性髓系白血病药物重定位、肝纤维化靶点和抗菌药物耐药机制中进行了实验验证。[18]
**付费与可用性**：当前通过 Google Labs/Gemini for Science 渐进开放，需要注册兴趣；官方没有公布面向个人的固定价格，企业合作也没有公开标准报价。[17][37]
**评价**：它不是完整的无人实验系统——湿实验仍由合作团队执行，Nature 论文也把直接接入自动化实验室列为未来方向。[18] 但对于“从庞杂文献中形成一组可竞争、可验证的机制假设”，它比单次聊天或普通 Deep Research 更值得关注，与你的病毒免疫与表观遗传研究高度匹配。
### 7. Robin：目前最贴近生物医学 Lab-in-the-loop 的代表
**作者与时间**：FutureHouse 团队，核心作者和工程负责人包括 Michaela Hinks、Ali Essam Ghareeb、Benjamin Chang、Ludovico Mitchener 等；预印本于 2025-05-19 提交，2026-05 发表于 Nature。[20][22]
**功能**：整合 Crow/Falcon 文献 Agent 与 Finch 数据分析 Agent，从疾病名称出发选择疾病机制和体外 assay、生成并排名候选药物，接收实验结果后分析并提出下一轮候选。其 dAMD 案例提出 RPE 吞噬增强策略，识别 ripasudil 和 KL001，并通过后续 RNA-seq 将 ABCA1 指向潜在机制；实体实验由人执行。[22]
**付费与可用性**：代码公开，但完整运行需要 Edison 平台 API 和模型 API；论文所用配置的典型 Agent 调用成本约 10.76 美元/轮，不含药物采购、细胞实验、测序和人工成本。当前仓库还明确要求购买 Edison credits 后创建 API key。[22][21]
**评价**：Robin 是对你最有启发性的架构，因为它没有假装机器人已经替代湿实验，而是把最耗认知的“查文献—选机制—选实验—读数据—再提假设”闭合起来。局限是示范领域和疾病路径仍较窄，且人类选择、实验质量和开放文献覆盖会决定上限。
### 8. Kosmos：当前最成熟的可购买数据驱动发现 Agent
**作者与时间**：由 Edison Scientific/FutureHouse 团队开发；Ludovico Mitchener 领导设计与工程，Benjamin Chang 领导发现综合、报告和评估，Michaela Hinks 负责监督，Andrew D. White 设计 world model，Sam Rodriques 负责科学工作与总体方向。技术报告于 2025-11-04 提交，产品于 11 月 5 日上线。[36][25]
**功能**：接收一个研究目标和一个或多个数据集，在最长约 12 小时内并行循环文献检索、数据分析、假设生成和 world model 更新，最后输出带代码与一手文献溯源的报告。论文报告平均每次读取约 1,500 篇论文、执行约 42,000 行分析代码，独立科学家判断 79.4% 的报告陈述准确。[36]
**付费与可用性**：2025 年首发价为 200 credits/次，即约 200 美元；旧订阅曾为 200 美元/月、650 credits。[25][34]
2026-05-19 的更新比旧定价页更新：新版 Kosmos 改为申请访问，新订阅尚待公布；学术用户从每月 650 credits 改为一次性 2,000 credits，标准 Literature/Analysis/Precedent Agent 仍有每月 10 个免费 credits，旧 Kosmos 界面仅暂时保留。[29]
官方定价页仍展示旧的 650 credits/月学术安排，因此当前处于政策切换期，实际额度应以账户和最新公告为准。[27][29]
**评价**：这是最值得在“已有高质量数据”条件下试用的系统，但不应把 79.4% 准确率理解成论文级可靠性。官方自己承认它会进入 rabbit hole，追逐统计显著但科学价值有限的结果，并经常需要对同一目标重复运行。[25] 它适合高价值数据资产的假设扩增，不适合替代 QC、统计审计或机制验证。
### 9. Biomni：对生物医学研究者最实用的通用执行 Agent 之一
**作者与时间**：Kexin Huang、Serena Zhang、Hanchen Wang、Yuanhao Qu、Yingzhou Lu 等，团队来自 Stanford、Genentech、Arc Institute、UCSF、Princeton 等，Jure Leskovec 参与领导；预印本于 2025-05-30 公开。[43]
**功能**：Biomni-E1 集成 150 个专用工具、105 个软件包和 59 个数据库；Biomni-A1 根据自然语言目标检索工具、生成计划并以代码组合执行。它覆盖单细胞与 ATAC-seq 分析、CRISPR 设计、疾病基因、药代性质、实验协议等，并对一个 CRISPR 克隆协议进行了湿实验验证。[43][42]
**付费与可用性**：官方仓库采用 Apache 2.0，可自托管；Web UI 已公开，但官网没有显示固定付费计划。自托管仍需约 11 GB 数据环境、模型 API 或本地模型算力；部分集成工具和数据库具有各自许可证。仓库警告当前会以完整系统权限执行 LLM 生成代码，生产使用必须放进隔离沙箱。[44]
**评价**：Biomni 还不是持续自主推进一个课题的 AI PI，但它对真实生物医学工作的工具覆盖和可执行性强于许多“自动写论文”系统。对你的课题，它是最适合低成本技术试验的开源候选。
### 10. The Virtual Lab：多学科 AI 团队与真实验证的代表
**作者与时间**：Kyle Swanson 为主要作者，James Zou、John Pak 等领导；2024 年预印本，2025 年发表于 Nature。[45]
**功能**：由 AI Principal Investigator 组织免疫学、计算生物学、机器学习和批评者 Agent，通过团队会议和个人任务协作，构建结合 ESM、AlphaFold-Multimer 和 Rosetta 的流程，设计 92 个 SARS-CoV-2 nanobody；湿实验验证得到可表达候选，并发现对 JN.1/KP.3 具有改善结合表现的候选。[45]
**付费与可用性**：研究框架而非公开 SaaS，没有标准价格；需要模型、结构预测与实验验证资源。
**评价**：它对你的呼吸道病毒主线很有直接启发：多 Agent 的价值不在于角色扮演，而在于把免疫学、结构生物学、计算设计和批评环节明确分工，并让实验验证成为硬门槛。
### 11. Lila Sciences：真正实体闭环，但属于企业级合作模式
**团队与时间**：Lila Sciences 在 Flagship Pioneering 内建设约三年后于 2025 年公开 Autonomous Science 平台；核心团队包括 CEO Geoff von Maltzahn、CTO Andrew Beam、Chief Scientist George Church 等。[30]
**功能**：以专有科学推理模型、工具链和 AI Science Factories 组成闭环，AI 生成假设、设计并执行真实实验、读取结果并持续优化，覆盖 DNA、RNA、蛋白、分子、细胞、材料、催化剂等领域。[30][31]
**付费与可用性**：没有个人自助订阅或公开价格。Lila Creation 以合作项目交付经验证的结构、协议和数据包；Lila Catalyst 向合作伙伴提供 Lila Iris 平台、AI Science Factories 与专家支持，属于企业 R&D 转型或 Lab-as-a-Service 合同。[32][33]
**评价**：从架构上看，它最接近跨领域实体实验闭环，但公开证据仍以公司案例和性能声明为主，透明度、复现性和定价都弱于论文型开源系统。除非未来以机构合作方式参与，否则不适合作为你的近期工具采购目标。

## 我的总体评价
### 1. “全流程”正在分裂成两条不同产品线
一条是以 The AI Scientist、Agent Laboratory、Kosmos 为代表的**计算与知识闭环**；另一条是 Adam、Coscientist、Robin、Lila 所代表的**实验反馈闭环**。前者扩展快、成本低、容易演示；后者更接近科学，但受仪器、样品、数据质量、安全和验证成本约束。
### 2. 当前最危险的误区是把“流程完整”当作“科学可靠”
Agent 可以完成每一步，却在每一步都留下小误差：检索漏文献、假设偷换概念、统计分析不稳、引用不准确、实验对照不充分。流程越长，误差越可能累积。Kosmos 的 79.4% 陈述准确率、Agent Laboratory 自动论文与人类接收论文之间的质量差距，以及 Sakana 对错误引用和方法严谨性的承认，都说明全自动产出仍必须经过逐层审计。[36][7][3]
### 3. 最值得买的不是“AI 科学家”标签，而是可验证接口
优先级应是：原始文献链接、可重跑代码、明确数据来源、实验记录、决策轨迹、版本化中间结果。能够把每个结论追溯到代码或一手证据的系统，比只给漂亮长报告的系统更有研究价值。
## 对你的建议
### 建议一：不采购一套“替代 Hermes”的封闭平台
你的最佳架构不是把整个知识库上传给某个科研 SaaS，而是让 Hermes 继续承担：
- 本地知识镜像检索与上下文组织；
- 文献下载、引用核验、论文卡片与讲义；
- 多 Agent 任务编排；
- 输出统一进入 `hermes-outbox`；
- 对外部科研 Agent 的结果做证据审计和归档。
外部科研 Agent 应被视为可替换的专用计算器，而不是新的唯一知识库。
### 建议二：近期优先级为 Biomni > Co-Scientist > Robin > Kosmos
1. **Biomni：先做低成本沙箱试验。** 选择一个已有金标准答案的小任务，例如一套公开 scRNA-seq 数据的细胞注释、CRISPR 筛选候选基因排序或一个已完成克隆方案的协议重建。把输出与人工结果盲法比较。不要让它直接访问 `/home/ubuntu/knowledge/`，也不要在非隔离环境执行其生成代码。
2. **Google Co-Scientist：立即申请 Hypothesis Generation。** 用于构建“假设池—反证—实验可行性—关键证据缺口”矩阵，尤其适合表观遗传修饰剂调控免疫、病毒受体变化与免疫逃逸机制。
3. **Robin：用于药物重定位和 assay 优先级。** 如果课题需要从疾病机制出发选择体外模型、候选分子和后续组学实验，Robin 的工作流最贴近你的需求；但实验候选必须由你审核，API 成本远小于湿实验成本。
4. **Kosmos：等到有干净且信息丰富的数据再用。** 最合适的是单细胞、多组学、CRISPR/条形码筛选计数、蛋白组或多个可交叉验证的数据集。不要为了“让 AI 找东西”上传未经 QC 的原始数据。先使用学术额度做一次高价值问题测试，再决定是否购买。
### 建议三：第一个试点应围绕真实课题，而不是玩具题
推荐从下面三个方向选择一个：
- **病毒受体条形码突变库**：输入突变设计约束、已有受体结构/功能证据和小规模筛选数据，要求 Agent 提出覆盖度、对照、测序偏倚与免疫逃逸判定方案。
- **表观遗传修饰剂与抗病毒免疫**：要求 Co-Scientist 生成机制假设树，每个假设必须列出支持证据、反证、关键混杂因素、最小验证实验和失败判据。
- **公开组学复现**：选择一篇与你研究方向接近且有公开数据的论文，让 Biomni 或 Kosmos在看不到原结论的条件下复现主要发现，再比较召回率、错误率、分析可重跑性和成本。
### 建议四：建立统一验收指标
每个 Agent 至少按以下指标记录：
- 引用可核验率；
- 关键文献召回率；
- 假设的新颖性、可证伪性和可执行性；
- 统计方法正确性和代码可重跑性；
- 是否识别批次效应、混杂因素和阴性对照；
- 人工修正时间；
- 模型/API/算力成本；
- 是否产生足以改变实验决策的新信息。
若 Agent 只是把你已经知道的内容写得更长，就不值得进入正式流程。
## 最终推荐
- **历史答案**：2004 Robot Scientist 是最早闭环先驱；2009 Adam 是早期自主发现新知识的标志。
- **影响力答案**：LLM 时代应重点看 ChemCrow/Coscientist、The AI Scientist、Google Co-Scientist、Robin、Kosmos。
- **实际选型答案**：你的近期投入顺序应是 Biomni 沙箱验证、申请 Google Co-Scientist、按课题试 Robin；等高质量组学或筛选数据就绪后，再用学术额度测试 Kosmos。
- **不建议近期投入**：为湿实验主线部署 The AI Scientist v2，或在没有机构合作预算时接触 Lila。
- **长期方向**：Hermes 作为本地证据与编排中枢，外部科研 Agent 作为可替换的专用执行层，人类实验与审计作为硬门槛。
