# 提示词导航
1. [[01 SMART原则目标拆解]]：把学习目标拆成每天 40 分钟、连续 7 天的行动方案。
2. [[02 碎碎念读书记录]]：先记录、整理和归档阅读碎片，阶段性需要时再总结分析。
3. [[03 讲解前大纲拆分]]：把所学内容拆成适合逐点讲解的大纲，不代替学习者作答。
4. [[04 八岁小学生测试官]]：用零背景儿童视角检验表达是否通俗、完整，并输出测评反馈。
5. [[05 杠精专家测试官]]：从专家视角追问底层逻辑、边界与简化程度，并输出高阶测评。
# 使用顺序
建议依次使用 01→02→03→04→05，覆盖目标设定、输入整理、输出准备、基础检验和高阶内化。
