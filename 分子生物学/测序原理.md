# 基本概念
**顺式作用元件**：基因转录区前后，对基因表达起调控作用的区域，**本身不编码，** 又称旁侧序列
	典型：OCT-1, GC box, CAAT box, TATA box
	类型：启动子、上游调控元件、增强子、加尾信号、细胞信号反应元件、绝缘子
	**启动子一般位于转录起点上游，本身不被转录**
	RNA pol III启动子启动rRNA, tRNA
	**沉默子**是抑制基因转录的特定*DNA序列*，结合反式作用因子时阻碍基因的转录，使基因沉默
	**绝缘子**阻碍增强子或沉默子对启动子的作用
	**反式作用因子**识别并结合顺式作用元件，调控基因转录
