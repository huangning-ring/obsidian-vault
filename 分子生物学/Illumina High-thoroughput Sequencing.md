# 高通量测序
> [!quote] 又称为下一代测序（Next Generation Sequencing, NGS），特点有：
- 大规模并行测序：一次运行可同时测定数百万至数十亿个DNA分子。
- 模板扩增原位化：在固相载体（如流动池flow cell或微珠）上进行局部扩增，形成“簇”（clusters）或“微反应单元”，实现信号放大。
- 边合成边测序（Sequencing by Synthesis, SBS）：绝大多数平台采用聚合酶介导的核苷酸掺入，并实时检测掺入事件。
- 短读长（short reads）：典型读长为50–300 bp（依平台而异），需通过重叠或配对末端策略进行组装。
- 数字化输出：原始数据为图像或荧光信号，经碱基识别（base calling）转化为FASTQ格式的序列与质量分数。
# 步骤
## 样本准备（文库构建）
### 文库
**定义：许多的DNA片段，在两头接上特定的DNA接头，形成的DNA混合物。**
中间的DNA序列未知、各不相同；两端的接头已知，且人工添加的。
### 步骤：
#### 1. DNA片段化、末端修复、加A尾
1. 将基因组DNA用超声波打断
2. 在两端用酶补平
3. 用Klenow酶在3'端加一个A，帮助结合T结尾的接头。
#### 2. 连接接头
| 名称                 | 是否固定    | 主要功能                                  |
| ------------------ | ------- | ------------------------------------- |
| 5':P5/P7           | 是       | 序列等于共价连接到Flowcell的序列，作为Oligo时也是Primer |
| i7 Index           | 否（样本特异） | 样本标识，多重测序                             |
| Read 1 Primer Site | 是       | Read 1 测序起始点                          |
| Insert             | 否（目标序列） |                                       |
| Read 2 Primer Site | 是       | Read 2 测序起始点                          |
| i5 Index           | 否       | 辅助样本标识（双 Index）                       |
| 3':P7/P5           | 是       | 氢键连接到流动池的Oligo                        |
#### 3. PCR富集
用P5/P7引物扩增文库DNA片段。
### 簇生成
扩增每个DNA片段，在Flowcell上完成。让DNA片段后续发出荧光的信号更强。
### Flowcell
长得类似载玻片，有多条Lane，两端有凹槽让液体出入。
![[Pasted image 20260221171942.png]]
在Lane内表面共价种植了大量Flowcell Oligo，3'端暴露。结合DNA文库上的P5、P7，使得被测序的DNA片段被固定在Flowcell上。
每段DNA单链都能结合到一个接头上
### 桥式PCR
1. 在DNA单链加载到接头上后，加入PCR反应体系。
2. 从引物端开始，生成了互补链。此时双链只有互补链和Flowcell共价连接。模板链是氢键连接到接头、互补链上的。
3. 加入NaOH，解链，模板链就被冲走，留下**互补链、Oligo的共价复合链**。
4. 加入缓冲液，使环境变为中性，**DNA单链就折叠，另一端与Flowcell上附近的另一种引物发生互补配对**，形成桥。此时互补链单链与引物1共价连接，与引物2互补配对
5. 加入PCR体系，从引物2开始合成新的链。新链的序列等于模板链。
6. 重复3-5，形成了DNA簇。由于过程中的冲洗不会影响DNA单链的位置，扩增产生的所有单链都比较近，且模板序列和互补序列数量相等。引物1共价连接反向链，引物2共价连接正向链。
### 去除反向链
用特定的酶切除引物1和反向链的连接，再用碱溶液冲洗。留在Flowcell上的就是全都是正向链的、位置集中的DNA簇。
## 测序
边合成边测序（Synthesis-by-Sequencing），每加上一个核苷酸就发一个荧光，激光颜色表示碱基种类
> [!method] 荧光修饰dNTP
1.Illumina公司建立，在普通dNTP的3'端连接叠氮基团，在延伸时可阻止聚合，一个循环只会延长一个核苷酸。
2.并且碱基加入后会发出特定荧光，通过激光扫描即可判断这个位置的DNA加入的是哪个碱基，进而推断正向链的碱基。 
1. 加入荧光修饰dNTP和PCR体系，进行循环。每次循环只会加入一个碱基
2. 碱基加入后激光扫描，根据荧光判断是哪个碱基，进而判断正向链的碱基。
3. 化学试剂切除叠氮基团、荧光基团，暴露3'端羟基
4. 重复1-3，边合成边测序。照相机拍摄视频，记录每个位置的荧光颜色变化，即可采集数据得到序列
5. 在Read1读段结束后，加入NaOH，洗去测序产生的Read1反向链。加入Index1引物来读取Index1（条形码BarCode)，标记来源。并生成Index1的反向链
6. 加入NaOH，洗去测序产生的Index1反向链。降低温度让DNA互补连接到引物2上形成桥
7. 加入PCR体系，从引物2开始合成完整的反向链。加入NaOH解链，使得Flowcell上又有等量的P7和P5接头连接等量的正反向链。
8. 用特定酶切除引物1和正向链的连接，洗去正向链，使得Flowcell上只剩下引物2连接的反向链。完成方向调换
9. 重复1-5，从相反方向边合成边测序。读出的序列即为Read2。**这就是双端测序，能扩大有效阅读范围。**
10. 双端测序完成后，用特定酶切除引物2和反向链的连接，洗去反向链。Flowcell上只剩下P5和P7接头。等待回收利用
**==至此，所有湿实验全部完成。==**
## 数据分析
测序反应的结果由激光显微镜照相机拍摄的视频记录保存下来。原始数据形式为：画面固定位置上的不同位置，在不同时间闪烁不同颜色的光点。每个光点代表一个簇的DNA，每个簇的DNA序列相同。
计算机计算每个点代表的序列，反向测序的数据则根据配对规则转为正向序列。产生上亿条序列。将相似的序列合并，与参考序列比对，填入参考序列的位置。
拼接后即可确定完整的DNA序列。由于开始时已经进行PCR富集，所以微小突变不会影响最终结果。
