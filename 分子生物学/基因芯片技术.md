# 生物芯片概念
微加工和微电子技术，有序地在硅片、尼龙膜等**固相支持物**上固定组织、细胞、蛋白、核酸、糖类等高密度**生物探针分子**构建的微阵列，与标记的待测样品中**靶分子杂交**并检测信号强度，实现对生物样本**准确、快速、高通量**的分析
# 生物芯片类型
## 信息芯片（一般情况下都是这个）
### 基因芯片
大量DNA探针分子固定在支持物，形成微阵列，与标记样品杂交，检测杂交信号
- 原位合成：利用光引导原位聚合技术与压电打印原位合成技术在玻片、硅片合成DNA探针 *（荧光、共聚焦、生物传感器等）*
- 点样合成：将预先合成的微探针徒步在硝酸纤维膜、尼龙膜或玻片上 *（只能荧光）*
蛋白质、细胞、组织芯片等
## 功能芯片
生物样品制备、毛细管电泳芯片、生物传感器等
# 生物芯片应用
1. 基因序列测定
2. 发现新基因
3. 检测基因差异表达
4. 基因多态性分析
5. 遗传学研究
6. 疾病诊疗
7. 药物研究
