# 文献正文摘要
**内容焦点：** 本文提供从人胚胎干细胞和患者特异性诱导多能干细胞构建混合肺类器官的平台。核心模型同时生成近端与远端肺上皮及自生间质，形成分支、芽样和球状结构，并可见纤毛、分泌、肺泡样和收缩性表型；免疫细胞与血管化可作为扩展模块加入。该系统适合发育、感染和药物反应研究，优势是细胞类型与组织互作范围较广且可传代冻存；限制是方法论文中的功能定量、供体代表性和跨批一致性证据不足，混合区域也会降低气道专属问题的解析精度。
