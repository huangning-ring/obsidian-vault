# 文献正文摘要
**内容焦点：**本文比较多种多孔聚合物支架，研究其物理化学性质如何引导人胚胎干细胞来源肺类器官在小鼠体内形成成人气道样结构。PLG 与 PCL 可支持类器官融合、扩展和假复层上皮形成，直接观察到基底与多纤毛细胞；PEG 条件则多停留在肺祖细胞状态。材料降解和可用空间主要调节气道形成位置、直径及移植物总体大小，使平台能够生成接近成人不同级别气道尺寸的组织。优势是把组织成熟与尺寸控制转化为可比较的材料设计问题；局限是本篇未直接验证完整分泌谱系和生理功能，材料效应部分仍属相关，系统依赖免疫缺陷动物且不适合高通量生产。
