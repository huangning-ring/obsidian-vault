# 文献正文摘要
**内容焦点：**本文把无外加细胞外基质的人 iPSC 肺类器官转入膜式搅拌生物反应器，实现一次生成大量游离组织。产物保留气道、肺泡和多类间质细胞，单细胞测序可分出基底、纤毛、Club、杯状、AECI/AECII及成纤维细胞群；整体标志与手工培养接近，但反应器产物偏向基底和成纤维细胞，肺泡样小泡较少。优势是扩大产量并连续控制传质环境，为自动化生产建立基础；局限是早期细胞准备仍未纳入反应器，剪切和氧环境尚未优化，缺少内皮、免疫与直接肺功能验证，也未证明批次间功能等效、冻存恢复和长期稳定性。
