# 文献正文摘要
**内容焦点：**本文以发育顺序为框架，将小鼠胚胎干细胞逐步转成肺祖细胞和近端气道祖细胞，再把同一思路移植到患者特异性囊性纤维化诱导多能干细胞。小鼠来源细胞在异位移植后形成含基底、俱乐部、多纤毛和黏液分泌细胞的上皮球体；人患者细胞可形成肺祖细胞和基底样上皮，但尚未完成多谱系成熟。平台适合解析早期肺命运决定和建立疾病细胞来源，优势是跨物种、跨多个人细胞系验证；限制是依赖异位环境，人模型缺乏直接生理功能，也没有长期扩增与规模化稳定性证据。
