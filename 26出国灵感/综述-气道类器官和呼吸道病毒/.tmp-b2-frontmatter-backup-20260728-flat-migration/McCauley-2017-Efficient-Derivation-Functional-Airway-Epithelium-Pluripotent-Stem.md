# 文献正文摘要
**内容焦点：**本文通过时序控制肺前体的发育信号，把人胚胎干细胞以及健康和囊性纤维化患者诱导多能干细胞转成上皮型近端气道类器官。模型形成管腔，并产生基底、分泌、杯状和多纤毛细胞；纤毛可活动，离子通道相关体积反应能区分健康、患者突变和同基因校正细胞。平台适合囊性纤维化机制、基因校正和药物反应研究，优势是疾病功能链与遗传对照完整；限制是组织结构仍较简化，缺少非上皮微环境和成人原代组织对照，长期扩增及冻存后功能稳定性也未充分证明。
