# 文献正文摘要
**内容焦点：**本文从人胚胎干细胞和诱导多能干细胞建立两个互补平台：含气道样上皮、肺泡标志细胞和自生间质的人肺类器官，以及富集胎儿肺芽尖祖细胞的上皮类器官。前者形成发育期气道样组织，适合研究上皮—间质互作；后者可长期扩增、形成近端与远端谱系，并具有损伤气道植入潜力。优势是两种配置分别覆盖组织互作和祖细胞命运问题，并与人胎肺基准比较；限制是体外组织偏胎儿样，人肺类器官难扩增，完整成熟功能往往需要移植环境支持。
