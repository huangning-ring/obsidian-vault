# 文献正文摘要
**内容焦点：**本文将永生化人支气管上皮细胞与肺成纤维细胞置于三维环境中，建立可观察分支形态发生的上皮—间质共培养模型。成纤维细胞能驱动上皮形成分支、细胞连接和腔样区域；更换间质状态或使用转化上皮变体后，形态可由有序分支转向侵袭，因此适合研究基质信号和肿瘤进展。优势是用明确对照证明间质互作的功能作用，重复性也优于单次原代模型；限制是上皮以基底样细胞为主，成熟谱系和生理功能不完整，且永生化细胞与真实供体组织仍有明显距离。
