# 文献正文摘要
**内容焦点：**本文提供从人胚胎干细胞和诱导多能干细胞获得纯上皮近端气道类器官的方法框架。细胞先形成肺前体，再建立带管腔的气道球体，基础配置主要含基底和分泌细胞，进一步分化可增加多纤毛细胞。该平台适合研究上皮内在发育、遗传病和药物反应，避免间质细胞干扰；优势是阶段性质量控制清楚且可用于不同细胞系，限制是肺前体产率和谱系比例波动显著，结构与功能验证有限，并未充分证明长期传代、冻存后功能稳定或成人原代气道一致性。
