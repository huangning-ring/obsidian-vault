# 评价维度说明 (C1–C9)

> [!important] YAML字段冻结声明（2026-07-30）
> **冻结依据**：38篇B2原始技术文献全量试填结果，8个评分维度均无全null字段，区分度充分。
>
> **冻结决定**：
> 1. C1–C9全部保留为独立列。C4为分类维度不评分，其余8个维度（C1/C2/C3/C5/C6/C7/C8/C9）各保留1–10分独立评分。
> 2. C5–C9全部独立保留，不降为子字段。依据：C7（均值5.0）和C9（均值5.1）虽普遍低分，但低分本身是"现状缺口"的关键发现，若降为子字段将丢失这一结论。
> 3. C3生理功能维度计划拆分为C3a黏液纤毛、C3b屏障通透、C3c离子转运、C3d感染应答四个子项。拆分前需先在10篇文献上试填，确认子项定义可行后再全量回填并冻结子结构。
> 4. 冻结后不再新增或删除列；如后续发现严重定义冲突，须经人工确认后修订并记录版本。
>
> **使用规则**：
> - 评分仅用于内部排序与矩阵可视化，正文以达成度描述（"X篇中Y篇≥8分"）为主，不在正文出现总分排名。
> - 总分不用于横向排名模型优劣，C4来源维度保持不评分。
> - 正文引用矩阵结论时必须限定口径："基于38篇可获取全文的评估"。

## 技术表现矩阵 (C1–C3, C5–C9 + 总分)
```dataviewjs
const pages = dv.pages('"26出国灵感/综述-气道类器官和呼吸道病毒/B2原始技术文献评级详情"')
  .where(p => p.file.name !== dv.current().file.name)
  .sort(p => p.file.name);

const dims = ["C1","C2","C3","C5","C6","C7","C8","C9"];
const dimLabels = {
  C1: "细胞组成", C2: "空间结构", C3: "生理功能",
  C5: "成熟一致", C6: "重复标准", C7: "样本代表", C8: "微环境适配", C9: "扩增规模"
};

function fmtScore(page, dim) {
  const score = page[dim + "_评分"];
  const status = page[dim + "_状态"];
  if (score != null && typeof score === "number") {
    const cls = score >= 9 ? 'style="color:#c00;font-weight:bold;"' : "";
    return `<span ${cls}>${score}</span>`;
  }
  return `<span style="color:#666;font-size:0.9em;">${status || "—"}</span>`;
}

function totalScore(page) {
  let sum = 0, cnt = 0;
  for (const dim of dims) {
    const s = page[dim + "_评分"];
    if (s != null && typeof s === "number") { sum += s; cnt++; }
  }
  return cnt ? sum : "—";
}

const headers = ["文献", ...dims.map(d => dimLabels[d]), "总分"];
const rows = pages.map(p => [
  p.file.link,
  ...dims.map(d => fmtScore(p, d)),
  totalScore(p)
]);

dv.table(headers, rows);
// TOKENS: C1_评分 C9_状态 C4_类型标签
```
