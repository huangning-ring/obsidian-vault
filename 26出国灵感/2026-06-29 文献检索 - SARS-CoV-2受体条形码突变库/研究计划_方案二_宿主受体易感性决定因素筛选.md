# 呼吸道上皮细胞受体条形码突变库在SARS-CoV-2感染易感性中的作用研究
## 一、研究背景与意义
### 1.1 科学背景
SARS-CoV-2感染和疾病严重程度在人群中表现出显著的个体差异，即使在相同暴露和疫苗接种背景下亦如此。这种差异的来源包括：**遗传因素、表观遗传状态、细胞表面受体表达水平、以及获得性免疫状态**。
**已知关键受体与辅助因子：**
- **ACE2**（血管升压素转换酶2）：SARS-CoV-2的主要入侵受体
- **TMPRSS2**（跨膜丝氨酸蛋白酶2）：S蛋白关键裂解的重要辅助因子
- **FURIN**：S蛋白原始位点的额外裂解
- **CatL/CatB**（cathepsin）：替代入侵途径
- **LDLR等相关基因**：可能影响病毒胞内转运
**现有研究的局限：**
- 大多数研究采用**单一基因敲除或过表达**，无法系统评估蛋白功能域的精细作用
- 缺少**高通量、多基因、多个体背景**的整合分析
- 既往工作以**体外细胞系**为主，缺乏真实呼吸道组织背景
- 对**表观遗传与遗传背景交互效应**的理解不足
### 1.2 研究意义
本研究建立的"宿主受体条形码突变库 × 气道类器官 × 多供体遗传背景"体系具有以下创新意义：
1. **方法论突破**：首次在真实气道组织（多供体）上进行宿主受体高通量精细突变筛选，系统绘制ACE2/TMPRSS2功能域的结构-功能关系
2. **生物学发现**：识别决定感染易感性的受体关键位点，揭示宿主遗传背景对感染易感性的调控机制
3. **临床转化**：为理解"为什么有人易感、有人抵抗"提供分子级别的解释，指导个性化防护和治疗策略
4. **技术创新**：建立可复用的宿主因素高通量筛选平台，可推广至其他病原体和遗传易感性问题
***
## 二、科学问题与研究假说
### 2.1 核心科学问题
**ACE2和TMPRSS2上哪些氨基酸位点对SARS-CoV-2的气道上皮感染至关重要，而这些位点的自然遗传变异如何解释人群中的感染易感性差异？**
**进一步的科学问题：**
1. **功能域精细性问题**
   - ACE2的S1/RBD结合结构域（PDZ domain）与肽酶结构域哪个更关键？
   - TMPRSS2的催化活性位点与基质特异性位点的相对贡献是什么？
2. **表观遗传交互问题**
   - 不同遗传背景供体（基于全基因组关联研究已识别的易感SNP携带者 vs. 耐受者）中，同一个受体突变的表型是否不同？
   - DNA甲基化、组蛋白修饰如何影响ACE2/TMPRSS2的表达量与功能？
3. **细胞类型特异性问题**
   - 纤毛细胞、杯状细胞、基底干细胞这三类主要上皮细胞对受体突变的敏感性是否有显著差异？
4. **病毒-宿主互作的动态性问题**
   - 感染早期（0-6h）与晚期（24-72h）对受体突变的依赖程度是否变化？
   - 不同病毒变体（原始株vs. Omicron）对这些受体改变的适应能力是否不同？
### 2.2 研究假说
**主假说：** 存在一个ACE2和TMPRSS2的"功能核心"（由关键氨基酸位点组成），这个核心对感染是充分必要的。自然人群中这些位点的遗传变异与已知的感染易感性SNPs（如3p21、6p21、12q24等）相关，解释了遗传易感性的一部分机制。
**次假说1：** 在耐受遗传背景供体的上皮细胞中，受体表达量的补偿性增加可以弥补功能上缺陷突变的影响（表观遗传补偿）。
**次假说2：** TMPRSS2的作用高度依赖S蛋白的特定位点，不同变体对TMPRSS2依赖性不同（变体适应假说）。

## 三、总体研究方案
### 3.1 技术体系框图
```
受体突变库设计
  ├─ ACE2 单氨基酸替换库 (功能域重点)
  └─ TMPRSS2 单氨基酸替换库
          ↓
      条形码标记
          ↓
  [混合条形码突变受体表达库]
          ↓
   气道类器官转导/转染
  (3-5个遗传背景供体)
          ↓
       SARS-CoV-2感染
  ├─ 原始株 + 多个变体
  └─ 时间梯度 (6h, 24h, 48h, 72h)
          ↓
  受体表达检测与病毒感染定量
  ├─ Flow cytometry (受体表达)
  ├─ 病毒RNA定量 (RT-qPCR)
  ├─ 单细胞RNA-seq (受体+病毒+炎症基因)
  └─ 细胞因子分泌 (IFN-β, TNF-α, IL-6)
          ↓
  条形码测序
  (每个受体突变的相对丰度变化)
          ↓
  受体-易感性景观绘制
  ├─ 基础表达量评估
  ├─ 感染依赖性评分
  └─ 供体间的异质性分析
```
### 3.2 主要技术模块
#### **模块I：宿主受体条形码突变库的设计与构建**
**步骤1：靶位点选择**
**ACE2突变靶区（优先级）：**
- **RBD结合结构域**（重点）：位置19-42（linker）、82-92（α-helix contact）、353-393（peptidase domain interaction）
  - 这些区域与SARS-CoV-2 S蛋白的RBD直接接触
  - 共约50-80个位点
- **PDZ binding motif**（C末端）：位置394-805
  - 涉及细胞内信号转导和膜定位
  - 约200-250个位点
- **翻译后修饰位点**：N-糖基化、磷酸化位点
  - 约10-20个关键位点
**ACE2总设计规模：250-350个单氨基酸替换**
**TMPRSS2突变靶区（优先级）：**
- **催化三联体**：His296, Asp345, Ser441（绝对保守）
  - 设计三个位点各替换为丙氨酸或其他赝酶不活跃变体
  - 共3个关键突变
- **基质结合结构域**（S1/S2/S3/S4 pocket）：位置192-250
  - 决定对S蛋白裂解位点的识别
  - 约40-50个位点
- **N末端信号肽与膜定位**：位置1-31
  - 影响蛋白亚定位和表达量
  - 约15-20个位点
**TMPRSS2总设计规模：60-80个突变**
**总设计规模：310-430个条形码化受体突变库**
**步骤2：条形码-受体融合序列合成**
- 设计310-430个唯一的12-14 nt DNA条形码（编码距离≥4，防止高错误率）
- 每个条形码与对应的受体突变基因关联（建立映射表）
- 采用全合成方式生成含条形码的完整cDNA（如Geneblocks或synthetic vectors）
- 条形码位置策略：
  - 选项1：在受体cDNA的3'UTR区域（推荐，对功能影响最小）
  - 选项2：C端标签（GFP或HA tag）之前（可同时追踪表达）
**步骤3：条形码库的质量验证**
- 序列准确性：Sanger测序验证50个代表性clone
- 表达验证：瞬时转染293T细胞，RT-qPCR验证各clone的mRNA相对丰度
- 蛋白表达：Western blot检验功能突变是否导致蛋白表达/稳定性严重下降
- 条形码与基因的一一对应：NGS验证库中条形码与突变基因的比例（>98%准确）
#### **模块II：气道类器官的多供体库建立与条形码受体库导入**
**步骤1：供体的选择与分组**
基于全基因组关联研究（GWAS）已报道的SARS-CoV-2易感位点：
- **易感供体**（n=2-3）：
  - rs11385942 (3p21) 风险等位基因携带者
  - rs657152 (6p21) 风险等位基因携带者
  - rs12610495 (12q24) 风险等位基因携带者
- **耐受供体**（n=2-3）：
  - 上述位点均为保护等位基因
  - 基因型通过靶向基因测序确认
- **中间表型供体**（n=1）：异杂合子或中间基因型
**步骤2：气道类器官的建立与特征**
- 从5位志愿者采集鼻黏膜和支气管活检
- 分离原代呼吸道上皮干细胞，建立ALI类器官
- 分化4-6周至成熟，验证细胞多样性与上皮屏障功能
- **关键验证**：
  - 内源性ACE2和TMPRSS2的基础表达水平（RT-qPCR、immunofluorescence）
  - 不同供体间的表达差异（2-5倍差异预期）
**步骤3：条形码受体库导入**
采用两种互补策略：
**策略A：病毒载体导入（推荐用于主要实验）**
- 构建AAV或lentiviral vector携带条形码-受体基因（含自身启动子或细胞特异性启动子）
- 优势：稳定整合，逐步扩大相关细胞群
- 劣势：滴度控制，潜在的插入位点效应
**策略B：瞬时转染（用于快速pilot）**
- 采用电穿孔或脂质体介导法转染条形码受体质粒库
- 优势：快速，无整合副作用
- 劣势：表达瞬时（48-72h），较难追踪单细胞水平
**步骤4：导入后的库验证**
- 导入效率评估：RT-qPCR检验条形码序列在细胞中的相对丰度
- 表达均衡性：测序验证各条形码的mRNA检出率（目标>90% detection rate）
- 受体蛋白表达确认：flow cytometry或immunofluorescence确认条形码-受体的蛋白表达
- 内源基因干扰：确认外源条形码-受体不严重抑制内源ACE2/TMPRSS2（若有则调整启动子或表达量）
#### **模块III：多供体、多时间、多病毒的感染筛选**
**步骤1：感染设计矩阵**
```
实验设计 (5供体 × 3病毒 × 4时间点 = 60个基础实验条件)

        │ 原始株(Wuhan) │ Omicron BA.2 │ XEC(如适用) │
供体1   │ 6h,24h,48h,72h│ 同上        │ 同上       │
供体2   │ 同上          │ 同上        │ 同上       │
供体3   │ 同上          │ 同上        │ 同上       │
供体4   │ 同上          │ 同上        │ 同上       │
供体5   │ 同上          │ 同上        │ 同上       │

每个条件包含：
- 生物学重复 n=3
- 感染MOI 0.5-2（优化）
- 技术重复 n=2（部分条件）
```
**步骤2：感染工艺优化**
- 预测试：在单一供体上优化感染参数
  - MOI梯度测试（0.1, 0.5, 1, 2, 5）
  - 感染时间与病毒回收时间点的最优配合
  - 受体导入后等待时间（确保充分表达，通常48h后）
- 关键指标：
  - 感染率>60%（单细胞RNA-seq检验）
  - 不同条形码受体的细胞存活率无显著差异（>80%）
  - 内源和外源ACE2/TMPRSS2的共表达分析
**步骤3：多维数据采集**
每个感染样本采集以下数据：

| 检测项 | 方法 | 目的 |
|-------|------|------|
| **受体表达** | Flow + qPCR | 衡量条形码-受体的蛋白和mRNA水平 |
| **病毒复制** | 病毒滴度(TCID50) + 病毒RNA(RT-qPCR) | 定量感染效率 |
| **宿主应答** | 细胞因子多重检测(MAGPIX或ELISA) | 先天免疫激活强度 |
| **单细胞转录** | scRNA-seq (10x Genomics) | 细胞异质性与受体-病毒-炎症的关联 |
| **条形码追踪** | 从感染细胞中提取RNA，测序读条形码 | 量化每个受体突变的相对丰度变化 |
#### **模块IV：条形码测序与数据分析**
**步骤1：条形码RNA的提取与文库构建**
- 感染72h后，从气道类器官中提取总RNA
- 使用特异性引物进行RT-PCR扩增含条形码的受体区域
- PCR产物加Illumina接头和样本多重条形码
- 通过凝胶电泳或磁珠法纯化目的片段
**步骤2：高通量测序**
- 采用Illumina NovaSeq或NextSeq（配对末端测序）
- 目标深度：每个样本>500万reads（以保证稀有条形码的检出）
- 共计约300+ 样本，总reads数>15亿条
**步骤3：生物信息学分析**
**数据处理流程：**
```
原始reads (fastq)
      ↓
质量控制（去除低质量、含N碱基）
      ↓
条形码提取（固定长度）
      ↓
与设计库比对（允许1个错配）
      ↓
丰度定量 (counts per million)
      ↓
跨样本规范化 (DESeq2 或 edgeR)
      ↓
受体-易感性指标计算
```
**关键分析指标：**
1. **基础表达指数 (Basal Expression, BE)**
   - 定义：无感染条件下，条形码-受体的相对mRNA丰度
   - 用途：识别导致表达缺陷的突变
   - 评判：BE < 0.5（相对于WT）为"表达缺陷突变"
2. **感染敏感性指数 (Infection Sensitivity, IS)**
   - 定义：病毒感染后，携带该受体突变的细胞中的病毒RNA相对含量
   - 计算：IS = (病毒RNA in 突变细胞) / (病毒RNA in WT细胞)
   - 评判：
     - IS > 1.5：该突变促进感染（易感表型）
     - IS < 0.67：该突变抑制感染（耐受表型）
     - 0.67 < IS < 1.5：中等影响
3. **供体异质性指数 (Donor Heterogeneity, DH)**
   - 定义：同一受体突变在不同供体间IS值的变异系数(CV)
   - DH > 0.3：高度供体依赖
   - DH < 0.1：供体无关，强健突变
4. **病毒变体适应指数 (Viral Adaptation Index, VAI)**
   - 定义：同一受体突变对不同病毒变体的IS比值
   - VAI(Omicron/WT) > 1.3：Omicron相对依赖此位点
   - 用途：评估变体进化的受体适应
5. **时间依赖指数 (Temporal Dependency, TD)**
   - 定义：IS值随感染时间的变化倍数
   - TD = IS(72h) / IS(6h)
   - TD > 2：早期依赖性强，晚期可代偿（补偿机制）
   - TD < 0.5：晚期依赖性强（可能反映二级感染）
**步骤4：统计与可视化**
- **热力图**：以供体×受体突变矩阵展示IS值
- **火山图**：X轴为效应大小，Y轴为统计显著性（q-value）
- **受体功能景观**：3D或network图展示突变位置、IS值、与既知变异的关系
- **供体聚类**：基于所有受体突变的IS谱聚类，识别表型相似的供体

## 四、技术路线详细说明
### 4.1 关键技术方案选择
#### **受体导入方式的对比与选择**

| 方面 | AAV病毒 | Lentivirus | 瞬时转染 |
|-----|--------|-----------|--------|
| **效率** | 中等(50-70%) | 高(70-90%) | 高(50-80%) |
| **持久性** | 长期(>3月) | 长期(>6月) | 短期(2-3d) |
| **单拷贝性** | 通常单拷贝 | 单~多拷贝 | 多拷贝 |
| **免疫反应** | 最低 | 中等(gag) | 无 |
| **制备难度** | 中等 | 高 | 低 |
| **用于本研究** | **主选** | 备选 | Pilot |
**理由**：AAV具有安全性、单拷贝整合、长期稳定的优势，特别适合高通量筛选
#### **条形码位置的选择**
**推荐方案：3'UTR同义插入**
```
ACE2-WT: [Start] → [ACE2 CDS] → [Stop] [3'UTR] [Polyg]
                                         ↑
                        条形码插入位置 (12nt barcode)
```
优势：
- 完全不影响ACE2蛋白序列和功能
- 条形码在mRNA上稳定存在，易于检测
- 避免翻译后修饰位点的干扰
#### **细胞类型分辨率**
采用**单细胞RNA-seq (scRNA-seq)**而非bulk RNA-seq的理由：
- 气道类器官含多种细胞类型（纤毛、杯状、基底干细胞等），它们的ACE2/TMPRSS2表达与感染易感性可能不同
- 通过scRNA-seq可以：
  - 识别哪些细胞类型受特定受体突变影响最大
  - 关联细胞类型-受体-病毒的三元关系
  - 发现新的病毒易感细胞亚群
### 4.2 数据质控标准

| 质控指标 | 标准 | 不达标的处理 |
|---------|------|----------|
| **条形码检出率** | >90%条形码 | 重新转导/转染 |
| **样本间相关性** | r > 0.85 (生物学重复) | 去除异常样本 |
| **病毒感染率** | >60%(scRNA-seq检验) | 重新优化感染MOI |
| **细胞活力** | >80% (存活率) | 降低感染压力 |
| **测序深度** | >500万reads/样本 | 追加测序 |
| **条形码饱和度** | >85% (设计库条形码的检出) | 增加测序深度 |

## 五、技术流程时间进度表（基于3年博士周期）
### 第一年：库构建与气道类器官系统建立
**第1-3个月：文献调研与方案设计**
- 系统文献回顾：SARS-CoV-2受体功能、GWAS易感位点、宿主因素与感染易感性
- 与团队讨论并确定310-430个靶位点
- 与合作者（如结构生物学团队）讨论选择理由
- **完成目标**：明确靶位点清单与条形码库设计
**第4-6个月：条形码受体库的合成与验证**
- 与IDT或类似服务商合作完成310-430个条形码-受体cDNA的合成
- 将条形码化cDNA克隆至AAV或lentiviral表达质粒
- Sanger测序验证50+ 代表性clone的准确性
- 构建条形码-基因映射表（Excel或数据库格式）
- **关键节点**：测序准确率>98%
- **完成目标**：获得310-430个条形码化受体库质粒
**第7-9个月：受体库的表达验证与功能确认**
- 采用电穿孔法将库质粒导入HEK293T细胞（快速筛选）
- RT-qPCR验证各个条形码-受体的转录丰度均衡
- Western blot检验蛋白表达，确认关键突变（如催化三联体）导致蛋白表达下降
- Flow cytometry确认条形码-受体在细胞膜上的表达
- **关键节点**：条形码库的各成员表达均衡（CV<30%）
- **完成目标**：获得验证过的、表达均衡的受体库
**第10-12个月：气道类器官系统建立与GWAS供体库构建**
- 获取伦理批准，采集3-5位志愿者的鼻黏膜与支气管活检
- 进行各供体的靶基因测序，确认GWAS位点的基因型（易感 vs. 耐受 vs. 中间）
- 建立各供体的ALI类器官，进行分化（4-6周）
- 验证类器官的细胞构成与屏障功能（TEER>200, ZO-1完整）
- 测定各供体的内源ACE2/TMPRSS2表达水平
- **关键节点**：获得5个遗传背景明确的成熟气道类器官库
- **完成目标**：5个供体×2个部位=10个成熟气道类器官库，备好用于导入
### 第二年：条形码受体库导入与高通量感染筛选
**第1-2个月：条形码受体库导入工艺优化**
- 采用单个供体（如易感表型）进行AAV或lentiviral导入的工艺优化
- 测试不同的病毒滴度、导入时间、选择条件
- RT-qPCR与flow cytometry验证导入效率与表达水平
- 测序验证条形码库的丰度均衡（目标Shannon指数>4.8）
- **关键节点**：导入效率>50%，条形码检出>90%
- **完成目标**：获得优化后的导入工艺，可复现应用于其他供体
**第3-5个月：多供体、库导入与感染前准备**
- 将优化后的工艺应用至5个供体
- 每个供体的ALI类器官导入条形码受体库
- 导入后等待48-72h进行充分表达
- 监测表达水平与细胞活力
- **完成目标**：5个供体×2个部位×库+技术重复 = 20+ 个库导入的成熟类器官
**第6-8个月：大规模感染与数据采集**
- 按实验设计矩阵进行感染：5供体 × 3病毒 × 4时间点 × 3生物重复 = 180个基础样本
- 对每个样本采集：
  - 受体表达验证（qPCR）
  - 病毒滴度定量（RT-qPCR）
  - 细胞因子分泌（MAGPIX多重检测）
  - 单细胞RNA-seq（分批进行，约20-30个样本走一批scRNA）
  - 条形码序列库准备
**重点**：进度管理
- 第6个月：完成所有原始株感染
- 第7个月：完成所有Omicron变体感染
- 第8个月：完成所有其他变体感染及追加样本
**完成目标**：180+ 感染样本的全部数据采集完成，条形码文库已测序
**第9-12个月：数据处理与初步分析**
- 条形码测序数据处理：质控、比对、丰度定量
- 计算各感染条件下的Infection Sensitivity (IS)、Donor Heterogeneity (DH)等指标
- 生成受体-易感性热力图与功能景观
- 进行初步统计分析，识别显著性关键位点
- 与GWAS数据库对接，寻找已知易感位点的分子解释
- **关键节点**：绘制完整的受体功能景观；发现10-20个关键位点
- **完成目标**：产出第一版受体-易感性分析报告
### 第三年：深度分析、验证与论文撰写
**第1-3个月：单突变株的验证与机制研究**
- 基于景观图筛选10-15个优先级突变（高IS、供体依赖性强）
- 生成单突变体AAV或表达质粒
- 在多个供体的类器官上重复感染试验
- 进行详细的时间动力学分析（6h, 12h, 24h, 48h, 72h）
- 结合scRNA-seq进行细胞类型特异性分析
- **产出**：单突变的详细验证报告
**第4-5个月：表观遗传与结构分析**
- 进行ATAC-seq或ChIP-seq，分析ACE2/TMPRSS2启动子的表观遗传景观
- 比较易感 vs. 耐受供体的启动子开放性与组蛋白修饰
- 采用PyMOL与分子动力学模拟，分析关键突变对蛋白结构的影响
- 与已知SARS-CoV-2 S蛋白RBD结构进行对接分析
- **产出**：表观遗传与结构机制报告
**第6-8个月：综合分析与临床转化**
- 整合遗传因素（GWAS易感位点）、表观遗传、细胞表型的多层次分析
- 提出一个综合模型解释"宿主遗传-表观遗传-受体表达-感染易感性"的关联路径
- 与已发表的宿主遗传易感性研究进行对比，寻找新的机制洞见
- 讨论对个性化防护、高危人群识别的临床应用潜力
- **产出**：综合分析报告与临床转化方案
**第9-12个月：论文撰写与投稿**
- 撰写主文（预计投稿至Nature Genetics / Cell Metabolism / Nature Immunology）
- 论文框架：
  - 方法创新：高通量宿主因素筛选平台
  - 关键发现：ACE2/TMPRSS2的功能景观与供体异质性
  - 机制洞见：表观遗传与宿主遗传易感性的整合模型
  - 临床意义：个性化风险评估与防护策略
- 撰写1-2篇补充论文（如特定供体表型、细胞类型特异性）
- **完成目标**：主文投稿；准备答辩

## 六、研究创新点与亮点
### 6.1 方法论创新
1. **宿主高通量筛选范式的建立**
   - 既往多数研究采用"敲除一个基因 → 测一个表型"的单基因模式
   - 本研究将深度突变扫描应用于宿主因素，实现310-430个突变的同步高通量评估
   - 在真实组织模型（气道类器官）而非体外细胞系上进行，增强生物学相关性
2. **多供体遗传背景的系统整合**
   - 首次在单一平台上，跨5个不同遗传背景的供体进行高通量宿主因素筛选
   - 能够区分通用关键位点 vs. 供体特异适应
   - 这种多供体设计是既往宿主因素研究所缺少的
3. **单细胞分辨率的易感性分析**
   - 结合scRNA-seq，能够在单细胞水平上关联：受体表达量 → 病毒感染 → 免疫应答
   - 识别异质细胞群中的病毒易感亚群
   - 提高精准度与生物学洞见深度
### 6.2 生物学创新点
1. **宿主受体功能景观的首次系统绘制**
   - 对ACE2和TMPRSS2的每个位点进行精细的功能评估
   - 识别"功能核心"位点（对感染必要充分）vs. "易感决定位点"（调节感染效率）
   - 与已知蛋白结构、GWAS易感位点进行关联
2. **表观遗传背景对宿主易感性的贡献**
   - 发现同一受体突变在不同供体间的效应存在显著差异（供体异质性）
   - 这种异质性可由启动子开放性、组蛋白修饰等表观遗传因素解释
   - 揭示"遗传 + 表观遗传"的协同调控机制
3. **病毒变体与宿主受体的协同进化**
   - 不同病毒变体（原始株 vs. Omicron vs. XEC）对相同受体突变的依赖程度不同
   - 提示病毒进化过程中会不断优化对宿主受体的适应
   - 有助于预测未来变体的受体适应趋势
### 6.3 临床与应用价值
1. **个性化感染易感性评估**
   - 基于患者的ACE2/TMPRSS2基因型与表观遗传背景，可预测其感染易感性
   - 指导高危人群的个性化防护措施（如更频繁的核酸检测、优先疫苗接种等）
2. **药物靶点发现**
   - 确定最关键的受体功能域，为阻断剂（如ACE2受体拮抗剂）设计提供指导
   - 识别可被小分子或抗体靶向的受体关键位点
3. **变体风险评估**
   - 当新变体出现时，基于本研究的受体适应指数，快速评估其人群中的传播风险
   - 支持公共卫生部门的监测与预警
### 6.4 技术可复用性
- 建立的宿主高通量筛选平台可推广至：
  - 其他呼吸道病毒（流感、RSV、腺病毒等）的宿主因素研究
  - 理解其他感染病的遗传易感性
  - 肿瘤或代谢疾病的宿主因素筛选

## 七、可能的难点与对策
### 7.1 技术难点

| 难点 | 原因 | 对策 |
|-----|------|------|
| 受体库导入效率不均匀 | AAV或lentiviral的滴定差异 | 采用等滴定病毒混合；使用qPCR标定滴定价 |
| 某些突变导致蛋白严重不稳定 | 结构破坏或引发降解 | 采用蛋白稳定预测工具（FoldX等）预筛选 |
| scRNA-seq的条形码检出不完整 | 条形码区域在cDNA合成中丢失 | 优化cDNA合成条件；使用full-length methods (10x Chromium) |
| 不同供体间的基础表达差异太大 | 遗传与表观遗传的自然差异 | 进行内部标准化（housekeeping基因）；增加供体数量 |
### 7.2 生物学不确定性

| 不确定性 | 应对方案 |
|---------|--------|
| 外源条形码-受体可能干扰内源基因功能 | 检验内源ACE2/TMPRSS2水平；必要时敲除内源基因后再引入库 |
| 瞬时高表达的外源受体可能导致非生理信号 | 在条形码-受体库中包含不同表达水平的版本（如不同启动子） |
| 类器官可能无法完全反映体内气道微环境 | 结合animal model进行验证；强调体外模型的局限 |
### 7.3 时间与资源管理

| 风险 | 预防措施 |
|-----|--------|
| 受体库合成延期 | 提前6个月启动合成订单；与供应商建立沟通 |
| 供体采集困难 | 提早建立伦理协议与患者招募渠道；准备多个备选供体 |
| scRNA-seq数据处理缓慢 | 提前学习10x Genomics数据分析pipeline；准备高性能计算资源 |

## 十二、与方案一的关联与互补
本方案（宿主侧）与方案一（病毒侧）形成一个完整的"病毒-宿主"互作框架：
- **方案一**揭示：病毒在黏膜免疫压力下**如何进化**（逃逸突变）
- **本方案**揭示：宿主遗传与表观遗传**如何决定**感染易感性
**两个方案的潜在协同点：**
1. 可在同一气道类器官系统上进行整合实验
2. 方案一发现的优先级逃逸突变，可在本方案的多供体库中进行易感性评估
3. 综合分析可揭示"易感宿主特别容易被特定病毒变体入侵"的现象
