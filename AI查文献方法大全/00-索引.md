## 快速对比

| 工具 | 免费额度 | 核心优势 | 最大局限 |
|------|---------|---------|---------|
| Scholar AI | 5 次一次性 | DOI 反幻觉 | 额度太少 |
| Paper Digest | 每日 5 次 | 价低 + 知识图谱 | 知名度有限 |
| Tavily | 1000 API 积分/月 | 研究报告 API | 需编程 |
| Consensus | 20 次/月 | Consensus Meter | 不含全文 PDF |
| Scite | 无真正免费层 | 引用分类 | 需付费 |
| Elicit | 2 份报告/月 | 结构化提取 | 敏感度低 |
| Semantic Scholar | **完全免费** | 2.35 亿 + API | 无 AI 分析 |
| ResearchRabbit | 50 篇种子论文/次 | 链式探索 | 底层数据部分过时 |
| Connected Papers | 5 张图谱/月 | 极简上手 | 额度较少 |
| Inciteful | **完全免费无限制** | SQL 透明 + Zotero | 需种子论文 |
| NotebookLM | 100 笔记本免费 | 封闭 RAG 反幻觉 | 仅 Gemini |
| OpenKnowledgeMaps | **完全免费** | 非营利开源 | 仅 100 篇 |
| Undermind | 约 5 次/月 | 深度发现曲线 | 搜索不可复现 |
