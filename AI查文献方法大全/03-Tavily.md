# Tavily

- **官网**：https://tavily.com
- **定位**：面向 AI Agent 的网页访问 API 层

---

## 实际功能

Tavily 本质是**开发者 API**，不是面向普通用户的消费级产品。无网页界面，需通过代码（Python/JS SDK 或 REST API）调用。

四大核心 API 端点：

1. **Search**：LLM 优化的网页搜索，支持域名过滤、日期范围、相关性评分
2. **Extract**：从任意 URL 提取干净的 Markdown/文本（含 JS 渲染页面）
3. **Crawl**：按深度/广度爬取整个网站
4. **Research**：给定研究主题，自主执行「搜索→抽取→分析→迭代」多轮，生成带完整引用的结构化研究报告

> 月均处理请求超 3 亿次，SLA 99.99%。2025 年完成 2500 万美元 A 轮融资，2026 年 2 月被 Nebius 收购。

## 补充发现（视频未提及）

1. **不是消费者产品**：无网页 UI，需注册 API Key 后通过代码调用——与视频暗示的用户体验有较大差距
2. **死链问题普遍**：GitHub 社区反馈返回链接含 404，因其依赖缓存而非实时验证
3. **无自有索引**：聚合多个第三方后端，结果顺序可能版本间漂移
4. **JS 渲染不稳定**：对 JavaScript 重页面采用缓存策略，有时返回大量无用内容（cookie 横幅等）
5. **400 字符查询限制**：在 gpt-researcher 等工具中超限会报错
6. **语言局限**：以英文为主，中日韩语言支持有限
7. **与 25+ 框架集成**：LangChain、LlamaIndex、CrewAI、Dify、Vercel AI SDK 等
