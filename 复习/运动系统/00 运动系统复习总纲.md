# 总体答题框架
1. **创伤题**：生命优先 → 评估血管神经与皮肤 → 临时固定 → 影像 → 判断稳定性与开放性 → 复位固定 → 功能锻炼。
2. **感染题**：全身中毒表现 + 局部红肿热痛/功能障碍 → 炎症指标、血培养/穿刺培养 → 早期足量敏感抗菌药 → 必要时引流清创 → 制动后康复。
3. **退变题**：机械性疼痛 + 神经受压表现 → 定位查体 → X线/CT/MRI → 先规范保守治疗 → 明确手术指征后减压与稳定重建。
4. **肿瘤题**：年龄 + 部位 + 影像学边界/骨膜反应/基质 → 分期 → 活检必须服从最终切除方案 → 多学科综合治疗。
# 高频鉴别

| 对比 | 关键差别 |
| --- | --- |
| 骨折专有体征 vs 一般表现 | 畸形、异常活动、骨擦音/骨擦感更特异；疼痛、肿胀、功能障碍不特异 |
| 脊髓休克 vs 神经源性休克 | 前者是损伤平面以下反射暂时消失；后者是交感中断导致低血压、心动过缓等循环障碍 |
| 急性化脓性感染 vs 结核 | 化脓性感染起病急、全身反应重；结核常缓慢、冷脓肿、窦道及渐进破坏 |
| 骨性关节炎 vs 类风湿关节炎 | OA以负重关节退变和机械性痛为主；RA为系统性自身免疫炎症，常对称累及小关节 |
| 良性 vs 恶性骨肿瘤影像 | 良性边界清楚、过渡带窄；恶性边界模糊、过渡带宽、侵袭性骨膜反应和软组织肿块更常见 |
# 最后冲刺顺序
- 第一轮：骨折并发症、开放性骨折、关节脱位、脊髓损伤、骨盆骨折。
- 第二轮：肩肘腕髋膝踝常见损伤的机制—畸形—神经血管并发症。
- 第三轮：颈椎病、腰椎间盘突出、感染/结核、骨肿瘤鉴别。
- 第四轮：畸形、慢性劳损、股骨头坏死及易混名词。
