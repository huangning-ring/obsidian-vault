# 运动系统畸形与骨折概述
> [!info] 教材锚点
> 第59章“运动系统畸形”起于印刷页600；第60章“骨折概述”起于印刷页613。正文为考点归纳，具体年龄界值与手术术式以教材和课堂为准。
# 运动系统畸形
## 先天性肌性斜颈
- 胸锁乳突肌挛缩使头偏向患侧、下颌转向健侧；久之可出现颜面不对称。
- 婴儿期先行被动牵伸、体位矫正和按摩；保守无效或年龄较大、挛缩固定者考虑手术松解。
## 发育性髋关节发育不良/脱位
- 婴幼儿注意髋外展受限、双下肢不等长、皮纹不对称；会走后可见跛行，双侧可呈鸭步。
- 检查随年龄选择超声或X线；治疗目标是早期获得并维持同心复位，同时避免股骨头缺血坏死。
- 年龄越小越倾向支具或闭合复位；年龄大、脱位高或闭合复位失败时需手术矫治。
## 先天性马蹄内翻足
- 典型构成：前足内收、中足高弓、后足内翻、踝跖屈。
- 出生后尽早连续手法矫形与石膏固定；残余马蹄常需跟腱处理，顽固或复发畸形再考虑进一步手术。
## 平足、𧿹外翻与脊柱侧凸
- **平足**：足弓降低不等于有症状；疼痛、疲劳和功能受限才决定干预强度。先控制体重、训练足内在肌、鞋垫支持。
- **𧿹外翻**：第一跖趾关节外翻伴第一跖骨内翻、内侧突出疼痛；宽鞋和支具可缓解症状，畸形明显且疼痛持续再评估手术。
- **脊柱侧凸**：冠状面侧弯并伴椎体旋转；前屈试验用于筛查，站立位全脊柱X线测Cobb角。观察、支具、手术取决于生长潜力和曲线进展。
> [!warning] 易错点
> “影像有畸形”不等于必须手术；畸形程度、进展风险、疼痛和功能损害共同决定治疗。
# 骨折总论
## 定义、成因、分类与移位
- **定义**：骨的完整性或连续性中断。
- **成因**：直接暴力、间接暴力、积累性劳损、病理性骨折。
- **按完整程度**：不完全骨折与完全骨折。
- **按皮肤黏膜完整性**：闭合性与开放性；开放性骨折首先是污染创面问题。
- **按稳定性**：稳定性与不稳定性；不稳定性决定再移位风险和固定策略。
- **常见移位**：成角、侧方、缩短、分离、旋转。描述移位通常以骨折远端相对近端的位置为准。
## 临床表现与检查
- 一般表现：局部疼痛、肿胀、瘀斑、功能障碍。
- 专有体征：畸形、异常活动、骨擦音或骨擦感；为避免加重损伤，不应为“查体阳性”反复诱发。
- 每次检查必须记录远端血运、感觉、运动和皮肤软组织状态。
- X线至少包含正侧位，并覆盖邻近关节；复杂关节内骨折常需CT，隐匿骨折或软组织损伤可选MRI。
## 并发症

| 时期 | 重点并发症 | 识别要点 |
| --- | --- | --- |
| 早期 | 休克 | 多发伤、大出血、骨盆或股骨骨折尤其警惕 |
| 早期 | 脂肪栓塞综合征 | 长骨/骨盆骨折后呼吸、神经症状及瘀点等 |
| 早期 | 重要脏器损伤 | 肋骨、骨盆、脊柱等骨折需系统评估 |
| 早期 | 血管神经损伤 | 苍白、无脉、感觉运动异常是急症信号 |
| 早期 | 骨筋膜室综合征 | 疼痛进行性加重、被动牵伸痛、感觉异常；脉搏消失是晚期表现 |
| 晚期 | 感染、骨髓炎 | 开放性骨折风险高 |
| 晚期 | 缺血性肌挛缩 | 骨筋膜室综合征不可逆后果 |
| 晚期 | 坠积性肺炎、压疮、血栓 | 长期卧床相关 |
| 晚期 | 骨化性肌炎 | 关节周围损伤后反复粗暴活动可诱发 |
| 晚期 | 创伤性关节炎、关节僵硬 | 关节面不平整或长期制动 |
| 晚期 | 缺血性骨坏死 | 股骨颈、腕舟骨等血供特殊部位高危 |
## 骨折愈合
- 大体过程：血肿炎症机化 → 原始骨痂形成 → 骨痂改造塑形。
- 临床愈合强调局部无压痛和异常活动、影像有连续骨痂、功能和负重达到相应标准。
- **影响因素**：年龄与全身营养、局部血供、感染、软组织损伤、骨折端接触、固定稳定性及不恰当活动。
- **延迟愈合**仍有愈合潜力；**不愈合**需寻找生物学或力学原因；**畸形愈合**是位置不良愈合并导致外观或功能问题。
## 治疗三原则
1. **复位**：恢复长度、力线和旋转；关节内骨折更强调关节面平整。
2. **固定**：外固定或内固定提供合适稳定性，同时尽量保护血供与软组织。
3. **功能锻炼**：在稳定允许范围内尽早活动未固定关节和肌肉，避免僵硬、萎缩与血栓。
## 现场急救
- 先按创伤流程保证气道、呼吸和循环；控制致命性出血。
- 开放伤口用无菌敷料覆盖，不现场盲目回纳骨端；妥善临时固定并记录固定前后血运神经。
- 怀疑脊柱损伤者保持轴线稳定搬运；疑似骨盆骨折避免反复挤压检查。
## 开放性骨折与开放性关节损伤
- 核心目标：降低感染、保存肢体和功能。
- 早期静脉抗菌药、破伤风预防、彻底清创、稳定骨折和软组织覆盖构成处理主线。
- 清创重点是扩大暴露、去除异物和失活组织、充分冲洗，并根据污染、组织活力和时间决定闭合策略。
- 开放性关节损伤需判断关节腔是否相通，充分清创冲洗、处理关节内损伤并建立稳定覆盖。
> [!danger] 必背急症
> 开放性骨折、骨筋膜室综合征、伴血管损伤的骨折脱位和不稳定骨盆骨折，都不能只按“拍片后慢慢处理”的普通骨折思路处置。
