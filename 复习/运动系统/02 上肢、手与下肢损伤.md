# 上肢常见损伤

| 损伤 | 典型机制/表现 | 关键并发症与处理重点 |
| --- | --- | --- |
| 锁骨骨折 | 肩部着地，局部隆起、肩下垂 | 注意皮肤顶压及锁骨下血管神经；多数可保守，明显移位或开放伤等评估手术 |
| 肩关节前脱位 | 外展外旋暴力；方肩、弹性固定 | 复位前后查腋神经和血运；复位后影像确认并康复 |
| 肱骨外科颈骨折 | 老年跌倒常见 | 腋神经、腋动脉；按移位和稳定性选择固定 |
| 肱骨干骨折 | 直接或间接暴力 | 桡神经损伤；记录腕背伸和虎口背侧感觉 |
| 肱骨髁上骨折 | 儿童伸直型常见 | 肱动脉、正中神经及骨筋膜室综合征；可遗留肘内翻 |
| 肘关节后脱位 | 跌倒手撑地 | 血管神经检查，早期复位、短期固定后尽早活动 |
| 桡骨远端骨折 | 手掌或手背着地 | Colles与Smith方向相反；关注腕管症状和复位后再移位 |
> [!warning] 复位前后都要记录
> 脉搏、毛细血管再充盈、感觉和关键肌力。只有复位后的记录，无法判断神经血管损伤来自原伤还是操作。
# 手外伤及断肢（指）再植
## 初诊评估
- 按皮肤、骨关节、肌腱、血管、神经顺序系统检查；任何小伤口都可能掩盖深部结构损伤。
- 伤口位置、污染、缺损、手指血运、两点辨别觉及主动屈伸必须记录。
## 处理原则
- 尽早清创，争取一期修复重要深部组织；骨折稳定和肌腱滑动环境同样重要。
- 肌腱修复后需在保护下早期康复，平衡断裂风险与粘连风险。
- 神经修复追求无张力、准确对合；恢复需要时间，远端感觉和运动随再生逐步改善。
## 离断肢体保存
- 离断肢（指）用无菌或清洁湿敷料包裹，置入密封袋，再将密封袋放在冰水混合环境中低温保存。
- 禁止离断组织直接接触冰块或浸泡在液体中；患者与离断肢体同时尽快转送有再植条件的中心。
- 再植适应证综合考虑全身情况、缺血时间、损伤平面和性质、功能收益及患者意愿。
# 下肢常见损伤

| 损伤 | 高频线索 | 易错点 |
| --- | --- | --- |
| 股骨颈骨折 | 老年跌倒、髋痛、患肢外旋短缩 | 股骨头血供受损，缺血坏死和不愈合风险高；嵌插骨折可仍能行走 |
| 股骨转子间骨折 | 老年、局部肿胀瘀斑较明显 | 血供较好但失血和内科并发症突出，重视早期稳定与活动 |
| 髋关节后脱位 | 屈髋屈膝受轴向暴力，患肢屈曲内收内旋 | 坐骨神经损伤；尽早复位以降低股骨头坏死风险 |
| 股骨干骨折 | 高能量损伤 | 隐性失血多、脂肪栓塞；先复苏和临时稳定 |
| 髌骨骨折 | 直接撞击或股四头肌强力收缩 | 伸膝装置是否连续决定功能和治疗策略 |
| 胫骨平台骨折 | 膝内外翻+轴向暴力 | 关节面塌陷、半月板/韧带损伤，警惕骨筋膜室综合征 |
| 胫腓骨干骨折 | 直接暴力常见 | 胫骨软组织覆盖差，开放伤、感染和不愈合风险高 |
| 踝关节骨折 | 旋转暴力 | 不只看骨块，还要判断踝穴稳定、下胫腓联合和内侧结构 |
| 跟骨骨折 | 高处坠落 | 检查腰椎及对侧跟骨；关注关节面和软组织肿胀 |
# 膝关节软组织损伤
## 韧带损伤
- ACL：急停扭转、快速肿胀、前向不稳；Lachman试验常用于评估。
- PCL：屈膝位胫骨受后向暴力；后抽屉和胫骨后坠提示。
- 内外侧副韧带：外翻或内翻应力损伤；需合并评估交叉韧带和半月板。
## 半月板损伤
- 扭转后关节线疼痛、弹响、交锁或打软腿；MRI有助于评估，但诊断应结合症状和查体。
- 治疗取决于撕裂部位、血供区、形态、稳定性、年龄和活动需求；可修复者优先保留组织。
# 创伤题通用作答模板
1. 写明受伤机制和典型畸形。
2. 先排除开放伤、血管神经损伤和骨筋膜室综合征。
3. X线正侧位，必要时加特殊位、CT或MRI。
4. 说明复位、固定和早期康复；关节内损伤强调恢复关节面与稳定性。
5. 补充近期和远期并发症。
