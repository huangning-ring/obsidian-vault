# 运动系统慢性损伤
## 共同机制
- 长期反复负荷超过组织修复能力，造成肌腱、腱鞘、滑囊、筋膜、骨或软骨的微损伤与退变。
- 局部疼痛、压痛和特定动作诱发是主线；影像用于排除其他病变和判断结构损伤。
- 治疗首先纠正负荷与动作模式，再配合短期制动、康复、镇痛；注射和手术应有明确适应证。
## 高频疾病

| 疾病 | 特征性线索 | 治疗重点 |
| --- | --- | --- |
| 肩袖损伤/肩峰下撞击 | 外展痛弧、夜间痛、力量下降 | 调整活动、肩胛与肩袖训练；全层撕裂结合功能需求评估修复 |
| 肱骨外上髁炎 | 腕背伸抗阻痛，外上髁压痛 | 减少重复伸腕、康复与支具；避免把所有肘外侧痛都叫“网球肘” |
| 桡骨茎突狭窄性腱鞘炎 | 拇指活动相关桡侧腕痛 | 活动调整、支具、局部治疗，顽固者松解 |
| 指屈肌腱狭窄性腱鞘炎 | 弹响、绞锁 | 减负、局部治疗，固定性绞锁可手术松解 |
| 腰肌劳损 | 腰部酸痛与压痛，无典型根性放射 | 核心训练、姿势与工效调整，排除红旗征 |
| 疲劳骨折 | 重复负荷后逐渐疼痛，早期X线可阴性 | 停止致伤负荷，必要时MRI；高风险部位需更积极处理 |
| 髌骨软骨相关疼痛 | 上下楼、久坐屈膝痛 | 调整负荷，改善髋膝力线与股四头肌控制 |
# 股骨头坏死
## 病因与表现
- 常见相关因素包括股骨颈骨折/髋脱位、糖皮质激素、长期大量饮酒等；也可无明确病因。
- 早期可仅有腹股沟区或髋部疼痛，逐渐出现活动受限和跛行；疼痛可放射至膝部。
## 检查
- X线早期可能正常；MRI对早期病变更敏感。
- 分期关注坏死范围、软骨下骨折、股骨头塌陷和继发骨关节炎。
## 治疗逻辑
- 未塌陷阶段以保存股骨头为目标：去除危险因素、减负及适合的保头手术评估。
- 明显塌陷、关节面破坏且症状影响生活者，关节置换通常更能恢复功能。
> [!warning] 易错点
> “MRI发现坏死”不等于立即置换；是否塌陷、坏死范围、症状、年龄与功能需求共同决定方案。
# 颈椎退行性疾病
## 分型思路

| 类型 | 主要表现 | 关键点 |
| --- | --- | --- |
| 神经根型 | 颈肩痛向上肢放射，皮节感觉和肌力改变 | 根性体征与影像责任节段对应 |
| 脊髓型 | 手笨、步态不稳、上运动神经元体征 | 进行性脊髓功能受损是重要手术评估信号 |
| 其他表现 | 椎动脉或交感相关症状需谨慎诊断 | 先排除心脑血管、耳源性等其他病因 |
## 治疗
- 无进行性脊髓损害或严重无力者通常先行规范保守治疗：教育、短期镇痛、康复与活动调整。
- 明确脊髓压迫并出现进展性功能障碍，或顽固根性症状合并责任节段压迫时评估手术减压与稳定。
- 粗暴颈部旋转和不恰当手法可能加重神经损伤。
# 腰椎间盘突出症
## 临床定位
- 腰痛伴单侧或双侧坐骨神经放射痛；咳嗽、喷嚏或增加腹压时可加重。
- 直腿抬高试验用于诱发坐骨神经张力症状；肌力、感觉、腱反射帮助定位神经根。

| 神经根 | 常见感觉区 | 代表肌力/反射 |
| --- | --- | --- |
| L4 | 小腿内侧 | 伸膝；膝反射 |
| L5 | 小腿外侧、足背及拇趾 | 拇背伸 |
| S1 | 足外侧 | 跖屈；跟腱反射 |
## 诊断和治疗
- MRI异常很常见，必须与症状、查体和责任节段一致；不能“见突出就诊断、见突出就手术”。
- 多数先行短期休息、镇痛、逐步恢复活动和核心训练；长期卧床不利于恢复。
- 手术指征重点：马尾综合征、进行性肌力下降，或充分规范保守治疗后仍有严重根性痛和功能障碍。
> [!danger] 马尾综合征
> 鞍区感觉异常、尿潴留或失禁、双下肢进行性神经障碍属于急症信号，应立即评估减压，不能继续常规理疗观察。
# 一条诊断链
机械性疼痛 → 判断是否有神经根或脊髓受压 → 查红旗征 → 查体定位 → 影像验证责任结构 → 先保守或按急症/进展性缺损转手术评估。
