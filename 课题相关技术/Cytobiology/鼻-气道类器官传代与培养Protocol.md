>[!note] 适用于：人源或小鼠鼻-气道类器官（Airway Organoids, AOs），基于 Wnt/Notch 信号调控的体外三维培养系统  
> 培养基体系：**ADF+++** = PneumaCult™-AL 系列 + Y-27632 + DAPT + Primocin  
> 类器官形态：球状结构（类器官球）
# 一、实验前准备
### 所需材料
- 预冷毛细玻璃管（12–13 mL）
- Acutase 消化酶（StemCell Technologies）
- TrypLE Express（Invitrogen）
- EDTA（0.5 M → 5 mM，PBS 稀释100倍）
- ADF+++
- Rising buffer（用于冲洗细胞）
- DPBS（无钙镁）
- 离心机（300g，4°C）
- 96 孔板、24 孔板、12 孔板、6 孔板（根据用途）
- Transwell（如 Corning 3450，孔径 0.4 μm）
- Cell Strainer(40μm)
- 细胞计数板、荧光显微镜、离心管、移液器、枪头
### 化胶要求
类器官球生长良好，直径约为100μm，边缘清晰，无纤毛。
# 二、化胶
化胶前先准备好稀释过的EDTA，枪头用Rinsing Buffer润洗防止粘附。
1. EDTA用PBS100倍稀释（0.5M→5mM），适量加入孔内，对着胶滴吹下，不碰到。
2. 枪头用Rinsing Buffer润洗，对着胶滴冲洗，完全化胶。
3. 3孔集一15ml管，控制在12-13ml
4. 300,4℃，5min
5. 移液管弃液，加ADF+++到12-13ml
6. 充分混匀后300，4℃，5min，洗去残余EDTA，弃液。
# 三、消化
1. 1:1混合Acutase、TryplE
2. 37℃消化15-30min，插入培养箱的孔中。每5min重悬细胞并观察，不能上下颠倒
> [!NOTE] 其中
3. 镜下观察到类器官球边缘不规则时，加入ADF+++混匀，终止消化。
4. 加入2ml含10000倍稀释Y27632的ADF+++
5. 用预冷的毛细玻璃管缓慢吹打至镜下呈现单细胞
6. 将40μm的Cell Strainer在离心管盖上用ADF+++润洗后，倒扣在离心管口
7. 缓慢过滤，取样计数。
8. 根据不同用途分管，加ADF+++到12-13ml，300g，4℃，5min，弃上清后备用
# 四、种胶12孔板
1. 基质胶:培养基-单细胞悬液=7:3，配制混合胶，在冰上保持液态
2. 12孔板下垫热水瓶，40μl/滴，垂直滴下。先每孔都滴一滴，测试该孔的浸润效果如何，然后再补充至3滴
# 五、Transwell
1. I型胶原用PBS稀释60倍，覆盖上室（24孔板100μl，12孔板300μl）。
2. 37℃ 2h，弃液后室温干燥半小时，PBS浸泡半小时后弃液
3. ALI:Proximal=1:1，加入下室（24孔板500μl，12孔板1ml，6孔板2ml）
4. 混合培养基重悬细胞，加入上室（100,300,1000μl）
# 六、高通量
1. Rinsing Buffer室温润洗尖底96孔板半小时，回收。
2. PBS洗板3次，最后吸干净
3. 水凝胶pf127:Proximal=1:50，加入适量体积细胞中混匀
4. 每孔100μl铺板，离心（气道：800g，5min；肺泡：600g，5min）
5. ……（转入新板，确保球被吸上来），转移后弃液，剩50ul后加入ALI 70μl
