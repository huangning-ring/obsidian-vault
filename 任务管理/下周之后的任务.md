# 【数据查找逻辑】
## 仅查询未完成的任务
not done 

## 仅查找下周之后的任务，携带指定标签的任务除外
happens after next week AND NOT ((tags include #例假提醒) OR (tags include #生日祝福))

## 只查找计划状态为“进行中”的任务
filter by function ["进行中"].includes(task.file.property("status"))

## 最多查找100条
LIMIT 100


# 【数据展示逻辑】
## 按任务的日期分组
group by happens

## 按任务紧急程度降序
sort by urgency

## 按任务名称升序展示
sort by description

## 显示/隐藏紧急程度数值
show urgency

## 显示/隐藏任务来源
show backlink

## 显示/隐藏循环生成规则
hide recurrence rule
