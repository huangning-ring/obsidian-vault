```tasks
# 【数据查找逻辑】
# 经查找本周已完成的任务
done in this week

## 计划日期或截止日期在本周或本周之前的任务
happens in or before this week

## 只查找计划状态为“进行中”，“暂停”，“已完成”的任务
filter by function ["进行中", "暂停", "已完成"].includes(task.file.property("status"))


# 【数据展示逻辑】
## 按任务完成日期分组
group by done reverse

## 按文件名分组
group by filename reverse

## 按任务名称升序展示
sort by description

## 显示/隐藏完成日期
hide due date

## 显示/隐藏紧急程度数值
show urgency

## 显示/隐藏任务来源
show backlink

## 显示/隐藏循环生成规则
hide recurrence rule
```
