### 为什么这个 Skill 值得装？
#### 资料 → 学习库，一步到位
PDF、网页、EPUB、Markdown，甚至整份代码库都支持。
它会自动扫描、提取内容、生成结构化笔记，打开 Obsidian 就能开始学。
#### 概念级进度追踪，弱项藏不住
不是简单统计“做了几题”，而是追踪每个概念的掌握程度：
> 弱 → 一般 → 好 → 掌握

哪里没懂一清二楚，复习效率翻倍。
#### 自适应出题，越考越精确
诊断 → 复习 → 巩固循环。
每次 4 题，根据你的薄弱点智能出题。答完自动更新进度，错题会重新包装成新语境再考。
#### 代码库新人福音，上手快 3 倍
自动分析项目架构、模块关系、数据流，生成新人 onboarding 笔记 + 练习题。
新同事来了直接丢一个 Obsidian 库，不用嘴对嘴教。
> Slogan：Content → Comprehension  
> 从资料到理解，闭环学习。

### 三步上手，从资料到学习库
#### 1\. 安装 tutor-skills（二选一）
方式一：
```
npx skills add RoundTable02/tutor-skills
```
方式二：手动安装
```
git clone
cd tutor-skills
./install.sh
```
#### 2\. 生成 Obsidian 学习库
```
cd ~/study-materials/
claude
/tutor-setup
```
它会自动检测资料类型：
-   PDF → 文档模式
-   有代码 → 代码库模式
然后生成完整的 StudyVault。
#### 3\. 开始测验，巩固知识
```
claude
/tutor
```
智能出题，4 题一轮。
诊断 → 复习 → 巩固循环，概念级进度追踪，直到全部掌握。

### Skill 是什么？
可以理解为给 AI 安装的“技能包”。
就像给手机装 App 一样，一个 Skill 就是一组 md 配置文件，告诉 AI：
> 遇到这种情况，请这样处理。

零代码、零配置。
