🔗：https://github.com/yikart/AiToEarn  
  
帮你在全球 13 个平台自动创作、分发、互动并变现。内容创业的终极外挂。  
  
6\. block/goose  
  
开源“AI 程序员”，几天暴涨 8 万多星。给一句话就能帮你搭项目、装依赖、写代码、跑测试，支持任何 LLM 包括本地模型。
