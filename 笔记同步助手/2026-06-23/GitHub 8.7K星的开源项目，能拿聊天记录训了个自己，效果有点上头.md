最近一直在试用WeClone这个开源项目，前前后后折腾了好几天，微调了两次模型，踩了不少坑，也看到了一些有意思的效果。
说实话，这项目的思路挺野的——拿你微信聊天记录当训练数据，用LoRA微调个大模型，再克隆你的声音，最后部署到微信/QQ/飞书这些平台上，搞出一个"数字版的你"。
我在想，要是能克隆一个自己去回复那些重复性问题，比如"这个接口文档在哪"、"啥时候提测"，也算变相省命了。不过实际跑下来发现，这事儿没那么简单。
项目地址：
```
1
https://github.com/xming521/WeClone
```
**这东西到底能干啥**
WeClone做的事情说起来不复杂：把你跟某个人的微信聊天记录导出来，自动处理成问答对格式，然后用LoRA微调Qwen2.5-7B之类的模型，让模型学会你的说话风格、惯用词、甚至语气词的频率。
再配合它的子项目WeClone-audio，把微信语音消息拿去训练一个语音克隆模型，最后通过AstrBot这个机器人框架部署到微信、QQ、企微、飞书上。你给人发消息，对方收到的就是一个说话风格和声音都像你的"数字分身"。
项目在GitHub上已经8.7K star了，可见不少人跟我一样对这个想法感兴趣。
**我实际跑下来的感受**
先说数据导出这一步。项目推荐用PyWxDump提取微信聊天记录，不支持微信4.0版本。我当时就是因为没注意版本号，折腾了半天发现导不出来，最后找了台装了3.9版本微信的老电脑才搞定。
导出格式是CSV，按联系人分文件夹放在./dataset/csv目录下。**建议只导出个人聊天，别用群聊记录**，群里各种@来@去、表情包、广告链接太多，数据质量很差。
数据预处理这一步，项目做了隐私信息过滤——默认去除手机号、身份证号、邮箱、网址。还有个blocked\_words禁用词词库，你可以自己加不想让模型学到的词句。这个设计挺细心的，毕竟聊天记录里敏感信息不少。
模型训练方面，默认用Qwen2.5-7B-Instruct，LoRA微调大约需要16GB显存。我用自己的4090跑，24G显存够用。没有高端显卡的兄弟可以考虑租云端GPU，有人用AutoDL的4090，几块钱就能跑完一轮微调。
训练完后的效果嘛……我拿了大概两万条跟一个多年好友的聊天记录去训练，最后loss降到3.5左右。测试的时候问"周末干嘛"，它回了一句"打球不？老地方"，语气确实挺像的。但问一些没覆盖到的话题，就开始胡言乱语了，典型的训练数据不够导致的效果拉胯。
**语音克隆这部分**
WeClone-audio用了大概0.5B参数量的语音模型，官方说能达到98.7%的声纹相似度。
我试了下，用几条微信语音消息做样本，训练出来的声音确实有那么点意思。但前提是你的语音消息质量得够好——微信的语音本身就有压缩，有些老语音还是各种环境噪音，训练出来的效果会打折扣。
而且语音克隆这功能对环境要求比较苛刻，依赖Tacotron或者WavLM之类的模型，安装过程容易出各种兼容性问题。我在这上面踩的坑比文本微调还多。
**部署到聊天平台**
部署用的是AstrBot，支持QQ、QQ频道、Telegram、微信、企微、飞书。我选了Telegram测试，流程大概是：
1.  1\. 部署AstrBot并配好消息平台
2.  2\. 启动WeClone的API服务：`python weclone/server/api_service.py`
3.  3\. 在AstrBot里新增OpenAI类型的服务商，API Base URL填WeClone的地址
有个坑要注意：微调后的模型不支持工具调用，必须先执行`/tool off all`关掉默认工具，否则模型输出会走样。
**适合什么人玩**
如果你是这几类人，可以试试：
-   • 想体验LLM微调全流程的开发者——WeClone把数据清洗、训练、部署整个pipeline都搭好了，比从零折腾LLaMA-Factory省事。
-   • 对"数字分身"这个概念好奇的，想看看AI能不能真的学会自己的说话风格。
-   • 想给客服/销售团队做个聊天风格训练的，理论上可行。
**不太适合的场景**
-   • 聊天数据太少（少于几千条）的，微调效果大概率不好，别浪费时间。
-   • 期望它能完美复刻一个人的——模型容量和数据质量都有限，顶多"有内味儿"，离以假乱真还远。
-   • Windows用户注意，项目主要面向Linux开发，Windows建议用WSL跑。
**风险提醒**
这东西涉及大量个人聊天数据，隐私问题必须说清楚。**项目支持本地化部署，数据不上传云端**，但前提是你自己注意别把训练好的模型随意分享出去。
而且从伦理角度讲，拿别人的聊天记录去克隆一个"数字版的TA"，这事确实有争议。我自己觉得，玩玩自己的数据可以，别拿别人的隐私搞事情。
**总结**
WeClone是个想法很野、落地还算认真的开源项目。它把一个看起来很科幻的概念——"用聊天记录造个数字的你"——拆成了可操作的步骤：数据导出、清洗、微调、语音克隆、部署。
实际效果取决于数据质量和数量，别抱太高期望，但作为一个折腾LLM微调的实战项目，值得花一两个晚上试试。训练出一个说话带自己口头禅的模型，看着它用你的语气回消息，确实有种微妙的乐趣。
项目还在快速迭代，当前版本有些功能不稳定，接口也可能变动。感兴趣的兄弟趁早玩，但别投入太多感情——毕竟它离真正的"数字分身"还有不少距离，目前更像是"一个模仿你聊天风格的对话模型"。
