## 学生党白嫖 Token 的 10 大秘诀

学生党白嫖 AI Token 指南：GitHub、硅基流动等 10 个免费渠道，无需信用卡轻松获取。

### 1\. GitHub Models —— 无需信用卡，主流模型随便调

GitHub 推出 Models 板块，把主流大模型打包成 API，任何账号都能直接调，无需绑卡。

适合学生党跑 demo、写课设、验证 idea。登录 GitHub 就能用，覆盖 OpenAI、Meta、Anthropic、Mistral 等多家模型。

### 2\. 硅基流动 —— 送 2000 万 Tokens，永久有效

-   信息来源：FreeLLM-API-KeyHub（7月8日更新最新）
-   注册 + 实名认证：送约 14 元代金券（～2000 万 Tokens）
-   小模型永久免费：Qwen、GLM 的小参数版本永远不花钱
-   邀请奖励：邀请 1 个好友各得 14 元代金券，不封顶
-   支持 DeepSeek-V3/R1、Qwen 全系列

操作：cloud.siliconflow.cn → 注册 → 实名认证 → 自动到账。

### 3\. Google AI Studio —— 2M 上下文，一本书塞进去读完

-   信息来源：awesome-free-llm-apis（6月16日更新，27 天内有效）
-   不需要绑信用卡
-   2M 上下文：一本书、几十篇论文一次性丢进去读完

操作：aistudio.google.com/app/apikey → 获取 API Key。

⚠️ 注意：免费 tier 不适用于欧盟 / 英国（中国 IP 可正常使用）。prompt 可能被 Google 用于模型改进。

### 4\. 智谱 AI —— GLM-4-Flash 永久免费调用

-   信息来源：FreeLLM-API-KeyHub（7月8日更新最新）
-   GLM-4.7-Flash：200K 上下文，永久免费
-   GLM-4.6V-Flash：128K 上下文，图文多模态也免费
-   注册还送 2000 万 Tokens 体验包
-   校园计划：学生专属认证优惠

操作：bigmodel.cn → 注册 → 免费模型直接调。

### 5\. Cloudflare Workers AI —— 每天白嫖 10000 神经元，50+ 模型

-   信息来源：awesome-free-llm-apis（6月16日更新，27 天内有效）
-   每天 10000 神经元（Neurons），换算下来每天能跑几百次推理
-   免费模型举例：
    -   Llama-4-Scout-17B（10M 上下文）
    -   GPT-OSS-120B（开源版 GPT 级模型）
    -   DeepSeek-R1、Gemma-4、Mistral-Small-3.1 等 50+ 个模型

操作：dash.cloudflare.com → 注册 → 获取 API Token。

### 6\. Groq —— 不用绑卡，每天 1000 次超快推理

-   信息来源：awesome-free-llm-apis（6月16日更新，27 天内有效）
-   自研 LPU 芯片，推理速度每秒 2600 个 token
-   不需要信用卡
-   免费：每天 1000 次请求
-   模型：Llama-3.3-70B、Qwen3-32B、GPT-OSS-120B

操作：console.groq.com/keys → 注册 → 获取 Key。

### 7\. 商汤大装置（SenseNova）—— 每 5 小时 1500 次免费调用

-   信息来源：FreeLLM-API-KeyHub（7月8日更新最新）+ 实测
-   商汤的免费额度有两个入口
-   在线版额外送深度求索 DeepSeek V4 Flash（500 次 / 5h），且支持图像输入理解

操作：注册 → 获取 API Key → OpenAI 兼容格式直接调。

> Key point 辉哥哥注：这个我在用，确实每天白嫖，速度也不错。

### 8\. OpenRouter —— 一个 Key 调遍 20+ 个免费模型

-   信息来源：awesome-free-llm-apis（6月16日更新，27 天内有效）
-   聚合平台，一个 API Key 覆盖所有免费模型，不用每个平台都单独注册

操作：openrouter.ai/keys → 注册 → 获取 Key → OpenAI SDK 直接调。

### 9\. Agnes AI —— 免费的多模态 API（对话 + 图片 + 视频）

-   信息来源：配置文件实测
-   Agnes AI 提供多个免费模型，一个 API Key 全包

操作：API 地址 [https://apihub.agnes-ai.com/v1，OpenAI](https://apihub.agnes-ai.com/v1%EF%BC%8COpenAI) 兼容格式。

> 技巧：免费额度足够日常使用，且模型覆盖文本 + 图片 + 视频，一个 Key 解决多种需求。
